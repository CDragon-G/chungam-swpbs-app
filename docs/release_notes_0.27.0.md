# 0.27.0 출시노트

담임 선생님이 한 주 단위로 반을 볼 수 있게 했습니다. 칭찬 우체통이 얼마나 쓰이는지
숫자로 보이고, 학교 나무가 새 소식을 먼저 알려줍니다. 연속 참여를 수업일 기준으로
세서 주말에 끊기지 않고, 불꽃 뱃지와 명예의 전당 불꽃 순위가 생겼습니다.

## 선생님께 (스토어에 올리지 않는 내용)

### 대시보드 '학생별' 탭 오류

서버 함수 `student_rows()` 안에서 `user_id` 를 표 이름 없이 썼는데, 이 함수가 돌려주는
칸 이름도 `user_id` 라서 Postgres 가 어느 쪽인지 정하지 못하고 매번 실패했습니다.
042 에서 이 함수를 만든 뒤로 계속 그랬을 가능성이 큽니다. 062 가 고칩니다.

앱에는 오류 원문 대신 알아볼 수 있는 안내가 나오도록 했습니다.

### 업데이트 안내 팝업 — 지금까지 한 번도 뜨지 않았습니다

"새 버전이 나왔어요" 팝업은 앱 맨 바깥(화면 목록보다 위)에 붙어 있었는데, 그 위치에서는
팝업을 띄울 수 없어 매번 조용히 실패했습니다. 로그인·가입 화면의 강제 업데이트 안내만
동작했습니다.

**0.27.0 부터**

- 앱을 켤 때, 그리고 다른 앱에 갔다가 돌아올 때마다 확인합니다. 학생들은 앱을 끄지 않고
  며칠씩 두기 때문에 켤 때 한 번만 보면 안내를 거의 보지 못합니다.
- '나중에' 를 누르면 30분 동안은 다시 띄우지 않습니다.
- 최소 버전보다 낮으면 닫을 수 없는 팝업이 뜹니다. 로그인해 있는 학생에게도 뜹니다.
- 학교 나무 말풍선도 "새 버전이 나왔어" 를 말합니다.

**0.26.0 이하를 쓰는 학생에게는 이번 업데이트 안내가 가지 않습니다.** 고친 팝업이
0.27.0 안에 있기 때문입니다. 스토어 자동 업데이트로 대부분 넘어오지만, 빨리 올리려면
학급에 한 번 안내해 주세요. 0.27.0 부터는 다음 업데이트부터 앱이 알아서 안내합니다.

**팝업이 뜨려면 `latest_version` 이 올라가 있어야 합니다.** 위 4번 SQL 이 그 일을 합니다.

### 학교 나무 말풍선

**먼저 말하는 소식** — 최근 3일 안에 온, 아직 읽지 않은 알림을 나무가 먼저 말합니다.
알림 센터에서 읽으면 더 말하지 않습니다.

| 학생 | 선생님 |
|---|---|
| 새 강화물이 들어왔어 (강화물 이름·가격) | 학맞통 안건 · CICO 권장 |
| 선생님께 칭찬받았구나 | 강화물 교환 요청 |
| 칭찬 우체통에 편지가 왔어 | 칭찬 편지 신고 |
| 오늘 자기점검 아직이지? / 1시부터! | 오늘 칭찬 편지 N통 |
| 명예 식집사까지 N점 · 지금 1등 | 오늘 N명 점검 · 참여율 |
| 다음 단계까지 양분 N | 새 버전 |
| 새 버전이 나왔어 | |

새 소식이 생기면 기다리지 않고 바로 그 말로 바꾸고, 그 뒤로는 세 번에 한 번꼴로 다시
말합니다.

**평소에 하는 말** — 학생 30여 개, 선생님 20여 개로 늘렸습니다. 아침·오후·저녁·밤에
섞이는 말이 다르고, 월요일·금요일·주말에만 하는 말이 있습니다.

### 연속 참여 — 수업일 기준

**전에는 달력 날짜로 셌습니다.** 058 부터 점검은 수업일에만 할 수 있으니 금요일에
점검해도 토요일이 되면 연속이 0 이 되었습니다. 그래서 **'7일 연속', '30일 연속'
뱃지는 지금까지 받을 수 없었습니다** (한 주 최대 5일).

**이제는 수업일만 셉니다.** 주말·공휴일·학사일정의 휴업일·방학은 건너뜁니다.

| 상황 | 연속 |
|---|---|
| 금요일 점검 → 월요일 점검 | 이어짐 (+1) |
| 수요일이 공휴일, 화·목 점검 | 이어짐 |
| 여름방학 앞뒤 수업일 점검 | 이어짐 |
| 수업일에 한 번 빠짐 | 다시 1 부터 |
| 오늘 아직 안 함 | 어제(직전 수업일)까지의 연속을 그대로 보여줌 |

- 연속은 점검이 저장될 때 서버가 한 번 계산해 둡니다. 학기 정리(060)로 원본을 지워도
  연속과 최고 기록은 남습니다.
- **063 을 실행하는 순간** 남아 있는 점검 기록으로 모든 학생의 연속·최고 기록을 다시
  계산합니다. 학기 정리로 이미 지운 기간은 되살릴 수 없어 그 이후부터 셉니다.
- 선생님 화면(학생별 탭, 담임반)의 연속도 같은 기준입니다.
- 기존 연속 뱃지 3개는 설명만 '수업일' 로 바꿨습니다. 이름과 그림은 그대로입니다.
- 연속 뱃지는 **지금까지 가장 길었던 연속**으로 판정합니다. 이미 끊겼더라도 한 번
  도달했으면 받습니다. 063 실행 뒤 학생이 0.27.0 에서 점검하면 받아야 할 뱃지가 한꺼번에
  들어옵니다.

### 불꽃 뱃지와 불꽃 표시

| 수업일 연속 | 뱃지 | 불꽃 색 |
|---|---|---|
| 1~4일 | — | 연한 주황 (불씨) |
| 5일 | 작은 불꽃 | 주황 |
| 10일 | 타오르는 불꽃 | 주황빛 빨강 |
| 20일 | 뜨거운 불꽃 | 빨강 |
| 50일 | 푸른 불꽃 | 파랑 |
| 100일 | 전설의 불꽃 | 보라·금 |

뱃지 그림은 기존 뱃지(금테 메달 + 빨간 리본)와 같은 모양으로 새로 그렸습니다.
불꽃 표시는 학생 홈 왼쪽 위, 내 기록, 담임반 학생 목록, 명예의 전당에 나옵니다.

### 명예의 전당 — 🔥 연속 참여 불꽃

이달의 학생 아래에 새 칸이 생겼습니다.

- **우리 반** 상위 3명 (학생·담임 선생님에게만)
- **전교** 상위 10명 — 3일 이상 이어가는 학생만
- 이름은 가운데를 가립니다 (`2-3 김*수`). 자기 줄은 색으로 표시됩니다
- 지금 이어지고 있는 연속 순입니다. 끊기면 순위에서 빠집니다

### 명예의 전당 — 보안 구멍 하나

`hall_of_fame()` 은 학교 id 를 받아 그 학교의 이달의 학생을 돌려주는데, 부르는 사람이
그 학교 소속인지 확인하지 않았습니다. 다른 학교 id 를 알면 그 학교 학생 이름(가리기
전 실명)을 받을 수 있었습니다. 앱은 자기 학교만 부르므로 실제로 쓰인 적은 없을 것으로
보지만, 063 에서 자기 학교만 볼 수 있게 막았습니다. 졸업·전출 학생도 뺍니다.

### 졸업·전출 학생

055 진급 처리로 학교를 떠난 학생은 프로필에 표시만 남기는데, 담임반 화면과 학급 목록은
그 표시를 보지 않고 있었습니다. 내년 3월 진급 뒤에 새 담임반 목록에 지난해 졸업생이
섞일 뻔했습니다. 062 가 뺍니다.

### 확인용

앱에서 **대시보드 → 학생별** 이 목록으로 열리면 062 가 적용된 것입니다.
(SQL 에디터에서는 로그인한 선생님이 없어 새 함수들이 빈 값을 돌려줍니다.)

063 을 실행한 뒤 연속 기록이 채워졌는지:

```sql
select count(*) as 학생수, max(best_days) as 최고연속, round(avg(current_days), 1) as 평균
  from checkin_streaks;

select name, condition_value from badges
 where condition_type = 'streak_days' order by condition_value;   -- 불꽃 뱃지 5개
```
