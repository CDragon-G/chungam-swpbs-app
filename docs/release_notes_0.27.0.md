# 0.27.0 출시노트

담임 선생님이 한 주 단위로 반을 볼 수 있게 했습니다. 칭찬 우체통이 얼마나 쓰이는지
숫자로 보이고, 학교 나무가 새 소식을 먼저 알려줍니다. 업데이트 안내 팝업이 뜨지
않던 문제와 대시보드 '학생별' 탭 오류를 고쳤습니다.

## 배포 순서

```
1. 062_teacher_week_praise_stats.sql   앱 배포 전에
2. 0.27.0 을 스토어에 올리고 출시 완료까지 기다린다
3. 버전 게이트 올리기                    ← 출시가 끝난 뒤에만
```

**062 는 반드시 앱보다 먼저.** 0.27.0 의 주간 점검표와 칭찬 우체통 숫자는 062 에서
만드는 서버 함수로 받습니다.

**062 만으로 바로 고쳐지는 것 (앱 업데이트 없이)**

- 대시보드 '학생별' 탭 오류
- 담임반·학급 목록에서 졸업·전출 처리된 학생 제외

3번은 두 컬럼을 같이 올립니다.

```sql
update app_releases
   set latest_version = '0.27.0', min_version = '0.27.0', updated_at = now()
 where platform in ('android', 'ios');
```

## 선생님께 (스토어에 올리지 않는 내용)

### 대시보드 '학생별' 탭 오류

서버 함수 `student_rows()` 안에서 `user_id` 를 표 이름 없이 썼는데, 이 함수가 돌려주는
칸 이름도 `user_id` 라서 Postgres 가 어느 쪽인지 정하지 못하고 매번 실패했습니다.
042 에서 이 함수를 만든 뒤로 계속 그랬을 가능성이 큽니다. 062 가 고칩니다.

앱에는 오류 원문 대신 알아볼 수 있는 안내가 나오도록 했습니다.

### 업데이트 안내 팝업 — 지금까지 한 번도 뜨지 않았습니다

"새 버전이 나왔어요" 팝업은 앱 맨 바깥(화면 목록보다 위)에 붙어 있었는데, 그 위치에서는
팝업을 띄울 수 없어 매번 조용히 실패했습니다. 로그인·가입 화면의 강제 업데이트 안내만
동작했습니다.

**0.27.0 부터**

- 앱을 켤 때, 그리고 다른 앱에 갔다가 돌아올 때마다 확인합니다. 학생들은 앱을 끄지 않고
  며칠씩 두기 때문에 켤 때 한 번만 보면 안내를 거의 보지 못합니다.
- '나중에' 를 누르면 30분 동안은 다시 띄우지 않습니다.
- 최소 버전보다 낮으면 닫을 수 없는 팝업이 뜹니다. 로그인해 있는 학생에게도 뜹니다.
- 학교 나무 말풍선도 "새 버전이 나왔어" 를 말합니다.

**0.26.0 이하를 쓰는 학생에게는 이번 업데이트 안내가 가지 않습니다.** 고친 팝업이
0.27.0 안에 있기 때문입니다. 스토어 자동 업데이트로 대부분 넘어오지만, 빨리 올리려면
학급에 한 번 안내해 주세요. 0.27.0 부터는 다음 업데이트부터 앱이 알아서 안내합니다.

**팝업이 뜨려면 `latest_version` 이 올라가 있어야 합니다.** 위 3번 SQL 이 그 일을 합니다.

### 주간 점검표

**담임반** 화면과 **대시보드 → 반별 → 학급 선택** 에 있습니다.

| 표시 | 뜻 |
|---|---|
| ✓ | 그날 점검함 (누르면 점수) |
| ✕ | 수업일인데 하지 않음 |
| ○ | 오늘, 아직 하지 않음 (점검이 열려 있음) |
| 휴 | 쉬는 날 (주말·공휴일·학사일정의 휴업일) |
| 빈칸 | 앞으로 올 날, 또는 오늘 오후 1시 전 |

- 오른쪽 '합계' 는 점검할 수 있었던 날 중 한 날 수입니다. 오늘 오후 1시 전에는 오늘을
  세지 않습니다.
- 맨 아래 줄은 날마다 한 학생 수입니다.
- 이번 주 한 번도 하지 않은 학생은 이름이 빨간색이고, 위에 인원이 나옵니다.
- ◀ ▶ 로 지난 8주까지 볼 수 있습니다. 학기 정리(060)로 원본을 지운 학기는 비어 보입니다.
- 선생님이면 어느 반이든 볼 수 있습니다. 반별 통계와 같은 범위입니다.

### 칭찬 우체통 숫자

**선생님 홈 → 오늘 현황** 과 **학급 칭찬 우체통** 화면 위쪽에 있습니다.

- 오늘 주고받은 편지 수 · 보낸 학생 수 · 이번 주 합계
- 담임 학급이 지정되어 있으면 "우리 반 학생이 오늘 받은 편지 수" 도 나옵니다
- 숫자만 보여줍니다. 누가 누구에게 보냈는지는 기존대로 담임·관리자만 학급 칭찬
  우체통에서 봅니다
- 숨김 처리된 편지(선생님 숨김, 받은 학생의 '사실이 아니에요')는 세지 않습니다

선생님 홈의 나무도 "오늘 아이들이 칭찬 편지를 N통 주고받았어요" 라고 말합니다.

### 학교 나무 말풍선

**먼저 말하는 소식** — 최근 3일 안에 온, 아직 읽지 않은 알림을 나무가 먼저 말합니다.
알림 센터에서 읽으면 더 말하지 않습니다.

| 학생 | 선생님 |
|---|---|
| 새 강화물이 들어왔어 (강화물 이름·가격) | 학맞통 안건 · CICO 권장 |
| 선생님께 칭찬받았구나 | 강화물 교환 요청 |
| 칭찬 우체통에 편지가 왔어 | 칭찬 편지 신고 |
| 오늘 자기점검 아직이지? / 1시부터! | 오늘 칭찬 편지 N통 |
| 명예 식집사까지 N점 · 지금 1등 | 오늘 N명 점검 · 참여율 |
| 다음 단계까지 양분 N | 새 버전 |
| 새 버전이 나왔어 | |

새 소식이 생기면 기다리지 않고 바로 그 말로 바꾸고, 그 뒤로는 세 번에 한 번꼴로 다시
말합니다.

**평소에 하는 말** — 학생 30여 개, 선생님 20여 개로 늘렸습니다. 아침·오후·저녁·밤에
섞이는 말이 다르고, 월요일·금요일·주말에만 하는 말이 있습니다.

### 졸업·전출 학생

055 진급 처리로 학교를 떠난 학생은 프로필에 표시만 남기는데, 담임반 화면과 학급 목록은
그 표시를 보지 않고 있었습니다. 내년 3월 진급 뒤에 새 담임반 목록에 지난해 졸업생이
섞일 뻔했습니다. 062 가 뺍니다.
