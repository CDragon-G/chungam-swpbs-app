## Google Play — 새로운 기능 (500자 제한)

```
규칙 건의함이 생겼습니다

학생이 규칙에 대해 하고 싶은 말을 보낼 수 있습니다.
보낸 내용은 관리자 선생님만 보시며, 다른 학생에게는 보이지 않습니다.

규칙별 실천 현황

어떤 규칙이 잘 지켜지고 어떤 규칙이 어려운지 한눈에 보실 수 있습니다.
70% 미만인 규칙은 재교육이 필요하다는 신호입니다.

명예 식집사

2주에 한 번, 자기점검을 가장 꾸준히 한 학생에게 500P를 드립니다.

이 밖에도

선생님 계정 관리, 퀴즈 문제 등록, 반별 참여율 화면 개선,
학교 성장 축하 안내를 더했습니다.
```

## App Store — 이번 버전의 새로운 기능

```
규칙 건의함

학생이 우리 학교 규칙에 대해 하고 싶은 말을 보낼 수 있습니다.
고쳤으면 하는 규칙, 새로 있었으면 하는 규칙 모두 좋습니다.

보낸 내용은 관리자 선생님만 보십니다.
다른 학생에게는 보이지 않으니 마음 편히 적을 수 있습니다.

규칙별 실천 현황

규칙마다 지켜진 비율을 모아 보여드립니다.
가장 어려운 규칙과 가장 잘 지켜지는 규칙을 먼저 알려드리고,
70% 미만인 규칙은 재교육이 필요한 신호로 표시합니다.
최근 7일, 30일, 90일 중에 골라 보실 수 있습니다.

명예 식집사

2주에 한 번, 지난 2주 동안 자기점검을 가장 꾸준히 한 학생을
명예 식집사로 선정해 500포인트를 드립니다.
다음 선정까지 남은 시간이 화면 위쪽에 표시됩니다.

선생님 계정 관리

관리자 선생님이 다른 선생님의 비밀번호를 바로 초기화하실 수 있습니다.
학교를 떠나신 선생님의 계정도 정리하실 수 있습니다.

퀴즈가 쉬워졌습니다

뜻이 통하면 정답으로 인정합니다.
"않았어요"와 "않아요"를 모두 맞는 답으로 봅니다.
학교가 직접 퀴즈 문제를 등록하실 수도 있습니다.

그 밖에

반별 참여율을 가로 막대로 바꿔 학급이 많아도 겹치지 않습니다.
학교 새싹이 한 단계 자라면 앱을 열 때 축하 안내가 나옵니다.
명단을 공백으로 구분해 붙여넣어도 정상 등록됩니다.
교환 신청 뒤에는 어디로 받으러 가야 하는지 또렷하게 안내합니다.
```
