# 0.32.0 출시노트

K-ODR 을 지난달 · 이번 학년도 · 전체 기간으로 볼 수 있게 했습니다. 학생을 누르면 그 학생의
기록을 처음부터 모두 볼 수 있습니다.

## 배포 순서

```
1. 071_student_rows_round.sql   ← 아직 실행하지 않았다면 (대시보드 '학생별' 탭)
2. 072_kodr_history.sql         ← 앱보다 먼저
3. 0.32.0 을 스토어에 올리고 출시 완료까지 기다린다
4. 스토어에서 학생 계정으로 '업데이트' 버튼이 보이는지 확인
5. latest_version 올리기        ← 플랫폼별로 따로
```

072 를 실행하지 않은 채 0.32.0 을 쓰면 월별 현황은 나오지만 '이번 학년도' · '전체' 와 학생별
누적 기록은 오류가 납니다. 072 를 실행해도 0.31.0 이하 앱은 그대로 동작합니다.

```sql
update app_releases set latest_version = '0.32.0', updated_at = now()
 where platform = 'android';   -- iOS 는 App Store 출시를 확인한 뒤 따로
```

## 선생님께

### 10월이 되자 K-ODR 이 사라진 것처럼 보인 이유

**기록은 지워지지 않았습니다.** K-ODR 화면의 현황이 '이번 달' 만 보여주게 되어 있어서,
10월 1일이 되자 9월 기록을 볼 방법이 없어진 것입니다. 9월 기록은 서버에 그대로 있고,
0.32.0 에서 다시 보입니다.

### 기간을 골라 보기

`K-ODR → 현황` 맨 위에서 기간을 고릅니다.

| 기간 | 보이는 것 |
|---|---|
| 월별 | 그 달에 기록된 학생과 건수. 화살표로 지난달로 넘깁니다. |
| 이번 학년도 | 3월부터 지금까지의 학생별 누적. 달별 건수가 위에 나오고, 누르면 그 달로 갑니다. |
| 전체 | 입학 뒤 지금까지의 학생별 누적. |

- 월별 목록에는 그 달 건수와 함께 `학년도 4건 · 전체 9건` 처럼 누적이 작게 나옵니다.
- 누적 목록(이번 학년도 · 전체)에는 지금 다니는 학생만 나옵니다.
- 'CICO 시작하기' 와 '학맞통 안건으로 올리기' 는 월별 보기에 있습니다. 지난달을 보면서도
  누를 수 있습니다.

### 학생별 누적 기록

현황에서 학생을 누르면 그 학생의 기록이 모두 나옵니다.

- 맨 위에 전체 · 이번 학년도 · 최근 30일 건수
- 자주 기록된 행동과 장소
- 학년도별 · 달별로 묶은 기록. 날짜, 행동, 장소와 상황, 즉각 대응, 2차 대응, 학생 반응,
  메모, 기록한 선생님이 나옵니다.
- 학년도마다 그때 몇 학년 몇 반이었는지 함께 나옵니다.

같은 학교 선생님이면 누구나 볼 수 있습니다. 새 학기에 담임이나 교과 선생님이 바뀌어도 그
학생의 지난 기록을 볼 수 있습니다. 학생 본인과 다른 학생에게는 보이지 않습니다. 학맞통 안건
여부는 이 화면에 나오지 않고, 지금처럼 관리자 선생님만 봅니다.

### 기록은 언제까지 남는가

- 진급해도 같은 학생의 기록으로 이어집니다. 기록이 학생 명단의 그 학생에게 붙어 있기
  때문입니다 (0.31.0).
- 졸업 · 전출로 명단에서 빠져도 기록은 지워지지 않습니다. 누적 목록에서만 빠집니다.
- 선생님 앱에서는 K-ODR 을 지울 수 없습니다. 지우는 화면은 원래 없었고, 이번에 서버
  권한에서도 막았습니다.
- 졸업한 학생의 기록을 일정 기간 뒤에 파기하는 기능은 아직 없습니다. 보존 기간을 학교
  방침으로 정하시면 그에 맞춰 넣겠습니다.
