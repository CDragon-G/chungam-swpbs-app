# 0.22.0 출시노트

학교 새싹의 성장 단계를 7단계에서 12단계로 늘렸습니다.

## 배포 순서

```
1. 0.22.0 을 스토어에 올리고 출시 완료까지 기다린다
2. 050_version_gate_0_22_0.sql   ← 출시가 끝난 뒤에만
```

050 은 버전 게이트만 올립니다. 실행하지 않아도 0.22.0 은 정상 동작하고,
구버전 사용자에게 업데이트 안내가 뜨지 않을 뿐입니다.
**심사 중에 실행하면 아무도 로그인하지 못합니다.**

이번 버전은 새로 실행할 함수나 테이블이 없습니다.

## 선생님께 (스토어에 올리지 않는 내용)

### 왜 늘렸나

충암중이 도입 한 학기 만에 Lv.7 열매나무에 닿았습니다. 최고 단계에
도착하면 더 키울 것이 없어지고, 성장 카드가 그냥 트로피가 됩니다.
계속 가꿀 것이 남아 있어야 카드가 살아 있습니다.

### 새 단계

| Lv | 이름 | 필요 점수 | 함께한 날 |
|----|------|----------|----------|
| 8 | 🧺 나눔나무 | 175 | 120일 |
| 9 | 🌲 이음나무 | 190 | 240일 |
| 10 | 🏞️ 작은 숲 | 205 | 400일 |
| 11 | 🌄 우리 숲 | 220 | 550일 |
| 12 | 🌏 모두의 숲 | 235 | 730일 |

점수 만점은 240 입니다 (성장 미션 80 + 활동 양분 160).

**Lv.1~7 은 바뀌지 않았습니다.** 기준도, 그림도 그대로입니다.
이미 Lv.7 인 학교가 내려가는 일은 없습니다.

### 시간 조건을 넣은 이유

점수만 기준으로 하면 활동을 몰아서 한 학교가 한 학기에 12단계를
끝냅니다. 그러면 같은 문제가 반복됩니다. Lv.8 부터는 점수와 함께
'자람을 도입한 뒤 지난 날'을 같이 봅니다.

점수는 찼는데 날짜가 모자라면 카드에 이렇게 나옵니다.

```
🌙 양분은 가득! 34일 더 함께 자라면 작은 숲이 돼요.
```

이때 진행바는 남은 날 기준으로 채워집니다. 잠긴 것이 아니라
기다리는 중이라는 것이 보이도록 했습니다.
