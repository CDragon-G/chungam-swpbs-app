# 0.19.0 출시노트

## 배포 전 SQL (중요)

`045_app_release_vote_admin.sql` 을 실행한 뒤, 스토어 심사가 **끝나면**
아래를 실행해야 사용자에게 업데이트 안내 팝업이 나갑니다.

```sql
update app_releases
   set latest_version = '0.19.0', updated_at = now()
 where platform in ('android', 'ios');
```

`min_version` 은 그대로 두세요. 옛 버전을 아예 못 쓰게 막고 싶을 때만 올립니다.

## Google Play — 새로운 기능 (500자 제한)

```
업데이트 안내

새 버전이 나오면 앱을 열 때 알려드립니다.
안내 창에서 바로 스토어로 이동해 업데이트하실 수 있습니다.

수업맛집을 더 자유롭게

학기 시작할 때 투표 기간과 요일을 미리 정해두실 수 있습니다.
금요일만 투표하도록 정하면 한 주를 지켜본 뒤 투표하게 됩니다.

진행 중인 투표의 이름과 투표권, 주차를 언제든 고치실 수 있고,
지난 투표 결과도 필요하면 삭제하실 수 있습니다.

버튼 하나로 선생님들께 투표 안내 알림을 보낼 수 있습니다.
```

## App Store — 이번 버전의 새로운 기능

```
업데이트 안내

새 버전이 스토어에 올라오면 앱을 열 때 알려드립니다.
안내 창의 버튼을 누르면 바로 스토어로 이동합니다.
꼭 필요한 업데이트일 때는 안내를 닫지 않고 업데이트하도록 안내합니다.

수업맛집 운영 기능

투표 가능한 날 지정
학기 시작할 때 투표 기간과 요일을 미리 정해두실 수 있습니다.
정해둔 기간이 아니거나 정해둔 요일이 아니면 투표 버튼이 잠기고,
왜 오늘은 투표할 수 없는지 화면에 표시됩니다.
금요일만 고르시면 한 주를 지켜본 뒤 투표하는 방식이 됩니다.

진행 중인 투표 수정
투표 이름, 교사 1인당 주당 투표권, 총 주차를 언제든 고치실 수 있습니다.
학기 중 사정이 바뀌어도 투표를 새로 만들지 않아도 됩니다.

지난 결과 정리
지난 투표 결과를 목록에서 삭제하실 수 있습니다.
그 투표에 들어온 표도 함께 정리됩니다.

투표 안내 보내기
버튼 하나로 우리 학교 선생님들께 투표 안내 알림을 보냅니다.
하실 말씀을 직접 적어 보내실 수도 있고,
비워두시면 오늘 투표 가능한 학년까지 담아 기본 문구로 나갑니다.
```
