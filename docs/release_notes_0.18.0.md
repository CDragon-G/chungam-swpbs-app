# 0.18.0 출시노트

## Google Play — 새로운 기능 (500자 제한)

```
학년마다 다른 시험 일정을 반영합니다

3학년은 진학 때문에 중간고사와 기말고사를 1·2학년보다 먼저 봅니다.
이제 수업맛집 투표에 학년별 시험 기간을 등록하시면,
그 기간에는 해당 학년만 투표를 쉬고 나머지 학년은 그대로 진행됩니다.

쉬어간 주는 그 학년의 주차에 포함되지 않습니다.
시험으로 투표하지 못한 주 때문에 진행이 밀리지 않습니다.

학년별로 총 주차를 따로 정하거나, 먼저 끝난 학년만 마감할 수 있습니다.
3학년 결과를 1·2학년보다 먼저 발표하고 시상하실 수 있습니다.
```

## App Store — 이번 버전의 새로운 기능

```
수업맛집 학년별 투표 일정

3학년은 진학 때문에 중간고사와 기말고사를 1·2학년보다 훨씬 먼저 봅니다.
시험 주간에는 정상 수업이 없어 투표할 근거도 없는데,
지금까지는 학교 전체가 하나의 일정으로 움직였습니다.

이번 버전부터 학년마다 일정을 따로 관리하실 수 있습니다.

투표 쉬는 기간

관리자 선생님이 학년별 시험 기간을 등록하시면,
그 기간에는 해당 학년만 투표가 잠기고 나머지 학년은 평소대로 투표합니다.
수학여행이나 체험학습 기간에도 쓰실 수 있습니다.

주차 계산

쉬어간 주는 그 학년의 주차에 포함되지 않습니다.
1·2학년이 4주차를 지날 때 3학년은 시험 주를 건너뛰고 3주차에 머뭅니다.
시험 때문에 라운드가 뒤로 밀리는 일이 없습니다.

학년별 마감

학년마다 총 주차를 다르게 정하실 수 있습니다.
정해진 주차를 다 채운 학년은 따로 마감해 결과를 공개할 수 있고,
그동안 다른 학년은 계속 투표합니다.

금요일 투표 알림도 그날 투표할 수 있는 학년만 안내합니다.
```
