# 0.33.0 출시노트

홈 화면에 움직임을 더했습니다. 하늘에 구름이 흘러가며 우리 학교 소식을 알려줍니다. 학교 나무는
이제 뒷걸음질하지 않고, 다음 레벨까지 칭찬이 몇 번 남았는지 말해 줍니다. 공지에 포스터 이미지와
기간을 붙여 학교 행사를 홈 배너로 홍보할 수 있습니다.

## 배포 순서

```
1. tool/check_applied.sql 실행 → 0행인지 확인   ← 072 까지 빠진 파일이 없는지
2. 073_live_home.sql                            ← 앱보다 먼저
3. 0.33.0 을 스토어에 올리고 출시 완료까지 기다린다
4. 스토어에서 학생 계정으로 '업데이트' 버튼이 보이는지 확인
5. latest_version 올리기                        ← 플랫폼별로 따로
```

073 을 실행하지 않은 채 0.33.0 을 쓰면 구름 소식이 나오지 않고, 나무 안내는 '양분 N점' 으로만
나오며, 이벤트 공지를 올리면 오류가 납니다. 073 을 실행해도 0.32.0 이하 앱은 그대로 동작합니다.
나무가 줄지 않게 하는 것은 서버에서 바뀌므로 구버전 앱에도 바로 적용됩니다.

```sql
update app_releases set latest_version = '0.33.0', updated_at = now()
 where platform = 'android';   -- iOS 는 App Store 출시를 확인한 뒤 따로
```

## 선생님께

### 구름 소식

학생 홈과 선생님 홈의 하늘에 구름이 오른쪽에서 왼쪽으로 천천히 흘러갑니다. 구름 하나에 소식
하나가 실립니다.

| 구름 | 예 |
|---|---|
| 방금 교환한 강화물 | `방금 · 2-3 신*용님이` / `'따뜻한 어묵' 교환!` |
| 오늘 숫자 | `오늘의 교환소` / `벌써 12번 교환했어요` · 오늘 자기점검 · 오늘 선생님 칭찬 · 칭찬 우체통 |
| 1위가 바뀐 순간 | `4분 전 · 이 주의 명예 식집사` / `3-2 김*수, 반 1위로!` · 이달의 명예의 전당 전교 1위 |
| 명예 | 2주 꾸준 식집사 선정 · 이달의 명예의 전당 전교 · 학년 1위 · 이 주의 명예 식집사 |
| 학교 이벤트 | `곧 열려요 · D-3` / `따뜻한 등굣길 캠페인` |

- 이름은 서버에서 가운데 글자를 가려서 보냅니다 (`2-3 신*용`). 명예의 전당 화면과 같은 방식입니다.
- 방금 일어난 일(30분 안)은 바로 다음 구름에 먼저 실립니다.
- 앱을 열어 둔 동안 1분마다 새 소식을 받습니다. 서버는 학교마다 1분 동안 결과를 보관해서, 홈을
  연 학생이 많아도 한 번만 셉니다.
- 0인 숫자는 말하지 않습니다. 소식이 하나도 없으면 하늘이 비어 있습니다.
- 구름은 터치를 받지 않습니다. 뒤의 메뉴나 당겨서 새로고침을 막지 않습니다.
- 휴대폰에서 '움직임 줄이기' 를 켠 학생에게는 흐르지 않는 구름 하나가 6초마다 소식을 바꿉니다.
- 체험 학교(자람체험중학교)의 소식은 체험 학교 안에서만 보입니다.

### 학교 나무가 뒷걸음질하지 않습니다

**왜 줄었나.** 성장 점수 가운데 몇 항목은 쌓이는 값이 아니라 '지금 상태' 였습니다. 최근 30일
참여율, K-ODR 증감, 교환소 강화물 개수, 공지 개수, 학생 절반 가입 여부입니다. 학생이 새로
가입하거나, 참여가 며칠 줄거나, 강화물 하나를 지우면 점수가 내려가 % 가 줄었습니다. 또 양분이
가득 차서 '함께한 날' 을 기다리는 순간에 진행률 계산 방식이 바뀌어 80% 가 50% 로 떨어져 보이는
일도 있었습니다.

**어떻게 바꿨나.**

- 이번 학년도에 한 번 오른 항목 점수는 그 아래로 내려가지 않습니다. 한 번 끝낸 성장 미션도 끝난
  것으로 남습니다. 새 활동은 그대로 더해집니다.
- 진행률은 양분과 함께한 날로만 계산합니다. 둘 다 늘기만 하므로 같은 레벨 안에서 % 가 줄지
  않습니다. 날 조건이 있는 레벨(Lv.8 부터)은 양분과 날의 평균입니다.
- 성장 미션 시트의 양분 표에서, 지금 값보다 최고 기록이 높아 그 값을 지키는 항목에는 `최고 기록`
  이 붙습니다.
- 3월 1일에 새 학년도가 시작되면 지금처럼 씨앗부터 다시 키웁니다.

**다음 레벨까지 칭찬 몇 번.** 진행바 아래와 나무 말풍선이 무엇을 몇 번 하면 되는지 알려줍니다.

- 예: `칭찬 26번이면 Lv.4!` · 양분을 채워도 날이 모자라면 `칭찬 36번이면 양분이 가득 차요` 와
  `Lv.12은 33일 뒤에 열려요` · 날만 남았으면 `33일 더 함께 자라면 레벨업!`
- 칭찬 양분은 한 학년도에 25점(칭찬 250번)까지입니다. 다 차면 나무가 수업맛집 투표나 교환 수령
  처럼 아직 양분을 더 받을 수 있는 활동을 알려줍니다.

### 이벤트 공지 — 예: 따뜻한 등굣길 캠페인

공지를 쓸 때 `이벤트로 홈에 홍보하기` 를 켜면 홈 배너와 팝업으로 홍보합니다. 관리자 선생님만 올릴
수 있습니다 (지금의 공지와 같습니다).

1. 교환소에 강화물을 먼저 등록합니다. 예: `따뜻한 어묵`, 가격, 재고.
2. `공지 · 이벤트` 화면에서 `🍢 예시 채우기` 를 누르면 따뜻한 등굣길 문구가 채워집니다. 받는 곳 ·
   때를 학교에 맞게 고칩니다.
3. 기간을 고릅니다. 시작일을 정하면 그 전까지 `D-3` 처럼 남은 날이 붙습니다. 마지막 날이 지나면
   배너와 팝업이 저절로 내려갑니다. 마지막 날은 꼭 정해야 합니다.
4. 배너 색을 고릅니다 (따뜻한 · 축제 · 자람 · 겨울). 포스터 이미지는 선택입니다. 이미지가 없으면
   고른 색으로 포스터를 만들어 보여줍니다.
5. 1번의 강화물을 연결하면 팝업에 `교환소에서 신청하기` 버튼이 생깁니다.

학생 홈에서는 이렇게 보입니다.

- 홈에 들어오면 이벤트 팝업이 하루에 한 번 뜹니다. 같은 날 다시 들어와도 뜨지 않습니다. 팝업이
  뜬 날은 깜짝 퀴즈가 쉬어 갑니다.
- 공지 자리에 이벤트 배너가 최근 공지와 6초마다 번갈아 나옵니다. 누르면 팝업을 다시 볼 수 있습니다.
- 구름 소식에도 `곧 열려요 · D-3` 으로 나옵니다.

참고

- 포스터 이미지는 3MB 이하 JPG · PNG · WEBP 이고, 앱이 올리기 전에 크기를 줄입니다. 학교 폴더에
  공개 이미지로 저장되므로 학생 얼굴이 나온 사진은 피해 주세요.
- 공지를 지우면 포스터 이미지도 함께 지웁니다.
- 0.32.0 이하 앱에서는 이벤트 공지가 보통 공지처럼 제목만 보입니다.

### 포인트를 써도 순위가 내려가지 않게

지금 앱에서 포인트로 학생 순위를 매기는 곳은 없습니다. 명예의 전당은 칭찬 · 점검 참여 · 점검 점수,
교환왕은 교환 횟수, 명예 식집사는 이번 주 점검과 칭찬으로 정합니다.

쓰면 줄어드는 숫자는 담임반 화면의 학생별 포인트와 반 전체 포인트였습니다. 둘 다 '남은 포인트' 라
교환소에서 쓰면 반이 뒷걸음질한 것처럼 보였습니다. 이제 크게 보이는 숫자는 이번 학년도에 모은
포인트이고, 남은 포인트는 그 아래 작게 `남은 300P` 로 나옵니다. 앞으로 포인트로 순위를 매기는 화면을
만들면 모은 포인트를 기준으로 합니다.

### 스토어 별점 요청

별점 창은 스토어가 알아서 띄우지 않고, 앱이 불러야 뜹니다. 이번 버전부터 기분 좋은 순간에 OS 기본
평가창(Android 는 Play 인앱 리뷰, iOS 는 App Store 평가)을 부릅니다.

| 누구 | 언제 | 조건 |
|---|---|---|
| 학생 | 교환 신청을 마쳤을 때 · 자기점검을 마쳤을 때 | 그런 순간이 10번 쌓이고, 앱을 쓴 지 2주가 지난 뒤 |
| 선생님 | 칭찬을 보냈을 때 | 그런 순간이 5번 쌓이고, 앱을 쓴 지 2주가 지난 뒤 |

- 한 번 물으면 120일 동안 다시 묻지 않고, 모두 3번까지만 묻습니다.
- 창이 실제로 뜰지는 OS 가 정합니다. iOS 는 1년에 3번까지만 띄우고, 이미 평가한 사람에게는 띄우지
  않습니다.
- "앱이 마음에 드세요?" 처럼 먼저 묻고 좋다고 한 사람에게만 띄우는 방식은 쓰지 않습니다. Play 정책이
  금지하는 방식(리뷰 게이팅)입니다.
- 체험 학교(엑스포 부스 · 특강 체험)에서는 띄우지 않습니다.
- 선생님 설정(톱니) 메뉴와 학생 마이페이지에 `자람 평가하기` 를 넣었습니다. 누르면 스토어의 자람
  페이지가 열립니다. 체험 학교에서는 보이지 않습니다.
- 스토어에서 받은 앱에서만 동작합니다. 개발용으로 설치한 앱에서는 창이 뜨지 않거나 제출되지 않습니다.

## 서버 변경 (073_live_home.sql)

| 무엇 | 내용 |
|---|---|
| `school_live_feed()` | 구름 소식. 학교마다 60초 보관 (`school_feed_cache`). 1위가 바뀐 순간은 `school_feed_events` 에 14일 보관 |
| `school_growth()` | 이름 · 반환 형태 그대로. 계산 결과에 `growth_apply_floor` 를 적용하고 `boost` 를 더함 |
| `school_growth_year.floors` | 학년도별 항목 최고값과 끝낸 미션. 서버만 씀 |
| `announcements` | `kind`(notice · event) · `image_url` · `event_start` · `event_end` · `theme` · `item_id` |
| 저장소 `notice-images` | 공개 버킷, 3MB. 그 학교 관리자 선생님만 자기 학교 폴더에 올리고 지움 |
| `homeroom_overview()` | 학생별 `earned` · 반 `total_earned` 추가 (기존 값은 그대로) |

기록은 하나도 지우지 않습니다.
