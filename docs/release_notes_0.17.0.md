## Google Play — 새로운 기능 (500자 제한)

```
담임반 관리가 생겼습니다

```

## App Store — 이번 버전의 새로운 기능

```
담임반 관리

선생님께서 맡고 계신 학급을 직접 선택하시면,
그 반 학생들의 자기점검 현황을 한 화면에서 보실 수 있습니다.

담임은 학기 중에 바뀌기도 하고 해마다 달라지므로,
가입할 때 정하지 않고 선생님께서 언제든 직접 고치실 수 있게 만들었습니다.
교사 홈의 담임반 메뉴에서 학년과 반을 선택하시면 됩니다.

보실 수 있는 것

· 오늘 우리 반에서 몇 명이 자기점검을 마쳤는지
· 학생별 참여율과 평균 점수, 연속 참여일
· 학생이 모은 포인트와 배지 수
· 3일 이상 점검하지 않았거나 참여율이 낮은 학생

참여율은 학사일정에 등록된 수업일을 기준으로 계산합니다.
방학이나 휴업일은 분모에서 빠지므로 실제 참여도가 정확하게 나옵니다.

가입 오류 개선

한 교실에서 여러 학생이 동시에 가입할 때
"너무 많이 시도했습니다"라는 오류가 나타나던 문제를 개선했습니다.
가입 과정에서 서버에 보내는 요청을 절반으로 줄였습니다.
```
