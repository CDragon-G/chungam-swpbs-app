# 0.33.1 출시노트

학교 나무 그림을 다시 다듬었고, 포인트 설정에서 바꾼 금액이 앱 화면에도 그대로 보이게 했습니다.

## 배포 순서

```
1. tool/check_applied.sql 실행 → 0행인지 확인   ← 073 까지 빠진 파일이 없는지
2. 074_point_amounts_for_all.sql                ← 앱보다 먼저 (늦어도 동작은 함)
3. 0.33.1 을 스토어에 올리고 출시 완료까지 기다린다
4. 스토어에서 학생 계정으로 '업데이트' 버튼이 보이는지 확인
5. latest_version 올리기                        ← 플랫폼별로 따로
```

074 를 실행하지 않아도 앱은 동작합니다. 그때는 화면의 금액이 기본값(칭찬 50P, 자기점검 100P,
개근 보너스 500P)으로 보입니다. 실제 지급은 지금처럼 포인트 설정 값을 따릅니다.

App Store 에 0.33.0 이 아직 '제출 준비 중' 이면, 그 버전 번호를 0.33.1 로 바꾸고 이 빌드를
고르면 됩니다.

```sql
update app_releases set latest_version = '0.33.1', updated_at = now()
 where platform = 'android';   -- iOS 는 App Store 출시를 확인한 뒤 따로
```

## 선생님께

### 학교 나무 그림

12단계 나무 그림을 모두 다시 다듬었습니다.

- 나무 기둥 사이에 남아 있던 흰 틈과 잎 가장자리의 흰 테두리를 없앴습니다.
- 바닥의 흰 타원을 어느 바탕에서도 자연스러운 그림자로 바꿨습니다.
- 그림을 더 크게(768px) 만들어, 큰 화면에서도 흐리지 않습니다.

### 포인트 설정이 화면에도 보입니다

**지급은 원래부터 바로 바뀌었습니다.** 포인트 설정(0.28.0)에서 금액을 바꾸면 그 뒤로 지급되는
포인트는 바뀐 금액이었습니다. 그런데 앱 화면 여러 곳에 금액이 숫자로 적혀 있어서, 칭찬을 100P 로
바꿔도 화면은 '+50P' 라고 말했습니다. 바뀌지 않은 것처럼 보였던 이유입니다.

이제 아래 화면이 포인트 설정 값을 그대로 보여줍니다.

| 화면 | 보이는 금액 |
|---|---|
| 칭찬하기 (설명 · 보낸 뒤 안내) | 칭찬 |
| 보낸 칭찬 목록 | 칭찬 |
| 학생 교환소 '포인트 적립 방법' | 자기점검 · 개근 보너스 |
| 자기점검 결과 | 실제로 받은 개근 보너스 |
| 2주 꾸준 식집사 선정 안내 | 2주 꾸준 식집사 |

처음 안내 화면(학생 · 선생님)은 금액 대신 "점검할 때마다 포인트" 처럼 바꿨습니다. 학교마다
금액이 다르기 때문입니다.

## 서버 변경 (074_point_amounts_for_all.sql)

| 무엇 | 내용 |
|---|---|
| `point_amounts()` | 우리 학교의 지금 금액 다섯 가지 (학생 · 선생님 모두 읽기) |

금액을 바꾸는 것(`set_point_rule`)은 지금처럼 관리자 선생님만 할 수 있습니다. 기록은 바꾸지 않습니다.
