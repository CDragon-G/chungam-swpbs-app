# 스포츠 리그 — 설계 (초안, 2026-10-30)

사제 경기(선생님 팀 대 학생 팀)를 포인트로 여는 기능. 이 문서로 함께 정한 뒤 만든다.

> **0.34.0 (077) 에 첫 단계가 들어갔다.** 함께 키우기에 '스포츠 경기' 옵션 — 선수 인원을 정하고,
> 학생이 보탤 때 선수 / 응원을 고른다. 응원은 목표의 30% 까지. 문제 1(보고만 싶은 학생)은 여기서 풀린다.
> 팀 만들기 · 친구 초대 · 선생님 승인(문제 2)은 아직이다.

## 1. 지금 방식과 문제

지금은 '함께 키우기'(단체 강화물)로 운영한다. 선생님이 "사제 축구" 를 열면 원하는 학생이
포인트를 보태고, 목표에 닿으면 경기를 한다.

| 문제 | 왜 생기나 |
|---|---|
| 뛰지 않고 보고만 싶은 학생도 포인트를 낸다 | 보탠 사람 = 선수 라는 구분이 없다 |
| 친한 친구들끼리 팀을 꾸리고 싶은데 모르는 학생이 끼게 된다 | 누구나 보탤 수 있어서 팀 구성을 정할 수 없다 |

## 2. 핵심 생각

**뛰는 사람(선수)과 보는 사람(응원)을 나누고, 팀은 초대로 꾸린다.**

- 선수 자리는 팀 주장이 초대한 학생만 차지한다 → 문제 2
- 누구나 '응원 포인트' 를 보탤 수 있지만, 응원은 선수 자리를 차지하지 않는다 → 문제 1

## 3. 정한 것 (2026-10-30)

| 항목 | 결정 |
|---|---|
| 응원 포인트 | 팀 목표에 넣되 **목표의 30% 까지만** 센다. 선수들이 대부분을 직접 모아야 한다 |
| 초대 범위 | **선생님이 경기마다 정한다** — 같은 반 / 같은 학년 / 전교 |
| 펀딩 시작 | **선생님이 팀을 승인한 뒤** 포인트를 모을 수 있다 |

## 4. 흐름

```
선생님: 경기 열기 ──▶ 학생: 팀 만들기 · 친구 초대 ──▶ 친구: 수락
                                   │
                          선생님: 팀 승인 (명단 확인)
                                   │
          팀원: 포인트 모으기 ◀── 누구나: 응원 포인트 (목표의 30% 까지)
                                   │
                    목표 달성 = 경기 성사 ──▶ 선생님: 날짜 확정 ──▶ 홈 구름 · 알림
                                   │
                          경기 후 선생님: 완료 (또는 취소 → 전액 환불)
```

### 4-1. 선생님 — 경기 열기

| 칸 | 예 |
|---|---|
| 종목 · 이름 | 피구 · "11월 사제 피구" |
| 선생님 팀 | 담당 선생님 (여러 명) |
| 학생 팀 인원 | 최소 8명 · 최대 12명 |
| 팀 목표 포인트 | 3,000P |
| 1인 최대 몫 | 목표의 40% (한 명이 다 내지 못하게) |
| 초대 범위 | 같은 반 / 같은 학년 / 전교 (학년 · 반 지정) |
| 신청 마감 | 11월 20일 |
| 이번 판 경기 수 | 3경기 (먼저 목표에 닿은 팀부터) |
| 경기 가능 시간 | 점심시간, 방과후 등 (메모) |

### 4-2. 학생 — 팀 만들기와 초대

- 주장이 팀 이름을 정하고, 범위 안의 친구를 검색해 초대한다.
- 초대받은 학생은 알림 → 수락 / 거절.
  - **거절해도 주장에게는 '응답 없음' 으로만 보인다.** 거절이 상처가 되지 않게.
- 최소 인원이 차면 주장이 '승인 요청' 을 보낸다.
- 한 학생은 한 경기에서 한 팀에만 선수로 들어간다 (응원은 여러 팀에 할 수 있다).

### 4-3. 선생님 — 팀 승인

- 팀 이름 · 명단을 보고 승인하거나, 이유를 적어 돌려보낸다.
- 승인 기준 예: 장난스러운 팀 이름, 특정 학생을 놀리는 구성, 인원 미달.

### 4-4. 포인트 모으기

- 진행 막대를 두 색으로 보여준다: **선수 몫** · **응원 몫**.
- 응원 몫은 목표의 30% 를 넘으면 더 받지 않는다 ("응원은 가득 찼어요").
- 1인 최대 몫을 넘으면 더 보탤 수 없다.
- 목표에 닿으면 '성사' — 더는 보탤 수 없고, 선생님에게 알림.

### 4-5. 응원

- 팀 목록에서 아무 팀이나 골라 '응원하기' 로 포인트를 보탠다.
- 응원한 학생에게 돌아가는 것 (정할 것, 6절):
  응원단 명단에 이름 · 응원 배지 · 경기 날 응원석

### 4-6. 성사 · 경기 · 완료

- 선생님이 날짜를 정하면 팀원 · 응원단에게 알림, 홈 구름에 "⚽ 2-3 번개FC 사제 피구 성사!"
- 경기 뒤 선생님이 '완료' — 결과(이긴 팀 · 점수)와 한 줄 소감을 남길 수 있다.
- 마감까지 목표에 못 닿거나 취소되면 선수 · 응원 포인트 모두 **전액 환불**.

## 5. 따돌림을 막는 장치

초대제는 '끼리끼리' 를 만들 수 있다. SWPBS 강화물이 누군가를 소외시키면 안 된다.

1. **최소 인원** — 두세 명끼리의 닫힌 모임이 되지 않게 (종목별로 선생님이 정함)
2. **선생님 승인** — 명단을 사람이 한 번 본다
3. **거절은 보이지 않게** — 주장에게 '응답 없음' 으로만
4. **열린 팀** — 선생님이 '누구나 들어올 수 있는 팀' 을 함께 열 수 있다. 팀이 없는 학생의 자리
5. **1인 최대 몫** — 포인트 많은 한 명이 팀을 '사지' 못하게
6. **누가 얼마 냈는지** — 학생에게는 팀 합계와 상위 3명만, 전체 명단은 선생님만 (지금 함께 키우기와 같음)

## 6. 아직 정할 것

| 질문 | 제안 |
|---|---|
| 응원한 학생 혜택 | 응원단 명단 + 응원 배지. 응원석은 학교 사정에 맞게 선생님 메모로 |
| 1인 최대 몫 기본값 | 목표의 40% |
| 최소 인원 기본값 | 축구 9 · 피구 8 · 농구 5 · 발야구 9 (선생님이 바꿈) |
| 팀이 성사된 뒤 선수 교체 | 주장이 요청 → 선생님 승인. 포인트는 옮기지 않는다 |
| 성사 팀이 경기 수보다 많을 때 | 먼저 목표에 닿은 순. 남은 팀은 다음 판으로 넘기기 또는 환불 중 선택 |
| 지금 열려 있는 함께 키우기 스포츠 펀딩 | 그대로 끝까지 진행. 새 경기부터 스포츠 리그로 |

## 7. 서버 설계 (안)

```
sports_events      경기 판 (선생님이 연다)
  id, school_id, sport, title, teacher_ids[], team_min, team_max,
  goal_points, member_cap_pct(40), supporter_cap_pct(30),
  scope('class'|'grade'|'school'), grade, class_num,
  apply_until, max_matches, slot_note, status('open'|'closed'|'done'), created_by

sports_teams       팀
  id, event_id, name, captain_id, is_open(열린 팀),
  status('forming'|'pending'|'approved'|'funded'|'scheduled'|'done'|'canceled'|'returned'),
  reject_reason, funded_at, match_at, result_note

sports_team_members  팀원
  team_id, user_id, status('invited'|'joined'|'declined'|'left'), invited_by, responded_at
  unique (event 안에서 joined 는 한 팀만)

sports_funds       보탠 포인트
  id, team_id, user_id, amount, role('player'|'supporter'), refunded

point_transactions.reason: 'sports_fund' · 'sports_refund'
```

함수 (모두 서버에서 범위 · 상한 · 상태를 검사한다)

| 함수 | 누가 |
|---|---|
| `open_sports_event` · `close_sports_event` | 선생님 |
| `create_sports_team` · `invite_to_team` · `request_team_approval` | 주장 |
| `respond_team_invite` · `leave_team` | 초대받은 학생 |
| `review_sports_team(approve / return, 이유)` | 선생님 |
| `fund_sports_team(team, amount)` | 팀원(선수 몫) · 그 밖의 학생(응원 몫, 30% 까지) |
| `schedule_sports_match` · `complete_sports_match` · `cancel_sports_team`(전액 환불) | 선생님 |
| `sports_board()` | 학생 · 선생님 — 열린 경기, 내 팀, 받은 초대, 응원할 수 있는 팀 |

알림: 초대 받음 · 팀 승인/반려 · 목표 달성 · 날짜 확정 · 취소(환불).
구름 소식(073): 경기 성사, 날짜 확정.

## 8. 화면 (안)

- **학생 · 교환소 → 스포츠 리그 탭**
  - 열린 경기 카드 (종목 · 마감 · 남은 경기 수)
  - 내 팀 (진행 막대 선수/응원, 팀원, 친구 초대, 포인트 보태기)
  - 받은 초대 (수락 / 거절)
  - 응원할 수 있는 팀 목록
- **선생님 · 교환소 → 스포츠 리그**
  - 경기 열기 · 승인 대기 팀 · 성사된 팀(날짜 정하기) · 지난 경기
- 경기 결과는 2차에서 '리그 기록' (반별 · 팀별 승패, 사진) 으로 모은다.

## 9. 순서 (안)

1. 1차 — 경기 열기, 팀 만들기 · 초대 · 승인, 선수 · 응원 포인트, 성사 · 날짜 · 완료 · 환불, 알림
2. 2차 — 리그 기록(승패 · 사진), 응원 배지, 열린 팀 자동 배정
