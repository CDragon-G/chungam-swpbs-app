# 0.35.0 출시노트

강의 · 연수 참여자가 체험 코드 하나만 넣으면 PIN · 이메일 · 비밀번호 없이 학생 화면을 체험할 수 있습니다.
이름은 '대구체험학생1', '대구체험학생2' … 처럼 자동으로 붙습니다. 2026-12-07 대구 강의(350~400명)를 위해
만들었고, 강사가 열어 둔 체험 학교에서만 됩니다. 실제 학교에는 아무 변화가 없습니다.

## 배포 순서

```
1. tool/check_applied.sql 실행 → 0행인지 확인     ← 077 까지 빠진 파일이 없는지
2. 078_demo_reset_admin_only.sql                   ← 체험 초기화는 관리자 선생님만
3. 079_demo_open_join.sql                          ← 체험 입장
4. 0.35.0 을 스토어에 올리고 출시 완료까지 기다린다
5. 스토어에서 '업데이트' 버튼이 보이는지 확인한 뒤 latest_version 올리기 (플랫폼별로 따로)
```

대구 강의 준비(익명 로그인 켜기 · 체험 학교 만들기 · 끝난 뒤 정리)는 `docs/daegu_demo_guide.md` 에 있습니다.

078 · 079 를 먼저 실행해도 0.34.x 앱은 그대로 동작합니다. 079 의 이름 가리기 변경은 '…체험학생N' 이름에만
적용되고, 실제 학생 이름은 지금처럼 가려집니다.

```sql
update app_releases set latest_version = '0.35.0', updated_at = now()
 where platform = 'android';   -- iOS 는 App Store 출시를 확인한 뒤 따로
```

## Google Play · App Store — 이번 버전

```
강의나 연수에서 받은 체험 코드로 자람을 바로 체험할 수 있습니다. 첫 화면의 '강의 · 연수 체험 코드가 있어요'를 누르고 코드를 넣으면 됩니다.
체험용 계정은 로그아웃하기 전에 한 번 더 묻습니다.
```

## 무엇이 바뀌었나

### 체험 코드로 들어오기

- 첫 화면에 **강의 · 연수 체험 코드가 있어요** 가 생겼습니다. 코드 6자리를 넣고 '체험 시작' 을 누르면 바로 학생 홈으로 갑니다.
- 로그인은 Supabase 익명 로그인입니다. 이름 · 이메일 · 비밀번호를 받지 않습니다.
- 서버가 차례로 번호를 매기고, 30명씩 반을 나눕니다 (1~30번 → 2학년 1반, 31~60번 → 2학년 2반 …).
  칭찬 우체통이 같은 반끼리만 되기 때문입니다.
- 강사가 `set_demo_join` 으로 연 체험 학교(is_demo)에서만 됩니다. 닫혀 있거나 실제 학교 코드를 넣으면
  '체험 코드를 다시 확인해 주세요' 만 나옵니다.
- 최대 인원(기본 600명)이 차면 더 들어올 수 없습니다.

### 체험 계정 로그아웃

- 체험 코드로 들어온 계정은 로그아웃하면 그 번호로 다시 들어올 수 없어서, 홈과 마이의 로그아웃에서 한 번 묻습니다.
- 엑스포 부스 계정도 홈 오른쪽 위 로그아웃 아이콘에서 묻습니다 (지금까지는 마이에서만 물었습니다).
- 실제 학교 계정은 지금처럼 바로 로그아웃됩니다.

### 체험 초기화는 관리자 선생님만 (078)

체험 학교의 보라색 '체험 초기화' 를 관리자 선생님만 누를 수 있습니다. 연수에서 교사 코드로 들어온 선생님이
눌러 다른 사람의 체험 기록을 지우는 일을 막습니다. 엑스포 부스 계정은 모두 관리자라 그대로입니다.
