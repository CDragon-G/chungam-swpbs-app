# 0.28.2 출시노트

업데이트 안내가 되풀이되던 문제를 고쳤습니다. 학생이 "업데이트하기" 를 눌러 스토어에
갔는데 '열기' 만 보이고, 돌아오면 또 묻던 상황입니다.

## 먼저 — 지금 바로 멈추는 방법 (앱 업데이트 없이)

되풀이의 원인은 **서버에 적어 둔 최신 버전이 스토어에 실제로 풀린 버전보다 앞서 있는 것**
입니다. 스토어에 올리고 '출시' 를 눌러도 심사·단계적 배포·전파 때문에 모든 학생에게
바로 보이지는 않습니다. 그동안 앱은 "새 버전이 있다" 고 믿습니다.

**1. 지금 서버가 뭐라고 말하는지 봅니다.**

```sql
select platform, latest_version, min_version, updated_at from app_releases;
```

**2. 스토어에서 학생 계정으로 실제 보이는 버전을 확인합니다.**
(개발자 계정 말고, 학생이 쓰는 보통 계정 기준입니다. Play 는 단계적 배포 비율,
App Store 는 '출시 준비 완료' 가 아니라 '판매 중' 인지 봅니다.)

**3. 서버 값을 스토어에 맞춥니다.** 예를 들어 스토어에 0.28.0 까지만 풀렸다면:

```sql
update app_releases
   set latest_version = '0.28.0', updated_at = now()
 where platform = 'android';

update app_releases
   set latest_version = '0.28.0', updated_at = now()
 where platform = 'ios';
```

플랫폼마다 풀린 버전이 다를 수 있으니 **따로 맞추는 편이 안전합니다.**

**`min_version` 은 서둘러 올리지 마세요.** 이 값보다 낮으면 닫을 수 없는 팝업이 떠서
앱을 쓸 수 없습니다. 스토어에 새 버전이 충분히 퍼진 뒤에, 서버 변경 때문에 구버전을
반드시 끊어야 할 때만 올리시는 것을 권합니다.

## 배포 순서

```
1. 067_version_gate_guard.sql   (앱과 상관없이 먼저 실행해도 됩니다)
2. 0.28.2 를 스토어에 올리고 출시 완료까지 기다린다
3. latest_version 올리기         ← 스토어에서 학생 계정으로 보이는 것을 확인한 뒤
```

## Google Play · App Store — 이번 버전

```
업데이트 안내가 되풀이되던 문제를 고쳤습니다.

한 번 닫은 안내는 하루 동안 다시 묻지 않습니다.
스토어에 아직 새 버전이 보이지 않을 때 안내 문구도 함께 보여줍니다.
```

## 선생님께

### 앱에서 고친 것

- **한 번 닫은 버전은 하루 동안 다시 묻지 않습니다.** '나중에' 를 누르든, 스토어에
  다녀왔는데 버전이 그대로든, 어느 쪽이든 같습니다. (0.27.0~0.28.1 은 30분마다 다시
  물었습니다)
- 팝업에 한 줄 덧붙였습니다.
  *"스토어에 '열기' 만 보이면 아직 새 버전이 퍼지는 중이에요. 조금 뒤에 다시 해보면 됩니다."*
- **강제 업데이트(최소 지원 버전 미만)는 그대로 계속 뜹니다.** 이건 넘어가면 안 되는
  안내라서 하루 쉬어가지 않습니다.

### 서버에서 막은 것 (067)

`min_version` 을 `latest_version` 보다 높게 저장하려고 하면 **거부합니다.**

```
최소 지원 버전(0.29.0)이 최신 버전(0.28.1)보다 높습니다.
이렇게 두면 아직 업데이트하지 못한 사람이 앱을 쓸 수 없습니다.
latest_version 을 먼저 올리세요.
```

예전에 052 에서 스토어 출시 전에 `min_version` 을 올려 전원이 로그인하지 못한 일이
있었습니다. 그 사고는 이제 서버가 막습니다.

**다만 서버가 막을 수 없는 것이 하나 남습니다.** `latest_version` 이 스토어보다 앞서는
것은 서버가 알 수 없습니다. 스토어에 뭐가 풀렸는지는 사람이 확인해서 올려야 합니다.

### 앞으로 올리는 순서 (권장)

```
1. 스토어에 올린다 → 출시 완료까지 기다린다
2. 학생 계정으로 스토어를 열어 '업데이트' 버튼이 보이는지 직접 확인한다
3. latest_version 을 올린다          ← 안내 팝업이 여기서부터 나갑니다
4. (필요할 때만) min_version 을 올린다
```
