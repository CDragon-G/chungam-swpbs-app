# 0.31.0 출시노트

K-ODR 을 한 번에 여러 학생에게 기록할 수 있게 했습니다. 앱에 가입하지 않은 학생도
명렬표에 있으면 기록할 수 있습니다.

## 배포 순서

```
1. 070_kodr_roster_students.sql   ← 앱보다 먼저
2. 0.31.0 을 스토어에 올리고 출시 완료까지 기다린다
3. 스토어에서 학생 계정으로 '업데이트' 버튼이 보이는지 확인
4. latest_version 올리기          ← 플랫폼별로 따로
```

070 을 먼저 실행하지 않으면 0.31.0 의 K-ODR 화면에서 학생 목록과 저장이 모두 실패합니다.
070 을 실행한 뒤에도 0.30.0 이하 앱의 K-ODR 은 예전처럼 동작합니다.

```sql
update app_releases set latest_version = '0.31.0', updated_at = now()
 where platform = 'android';   -- iOS 는 App Store 출시를 확인한 뒤 따로
```

## 선생님께

### 여러 학생을 한 번에

`K-ODR → 기록하기 → 학생 선택` 에서 여러 명을 체크할 수 있습니다.

- 한 번에 30명까지 고를 수 있습니다.
- 학생마다 같은 내용으로 **한 건씩** 저장됩니다. 학생별 누적 건수와 CICO · 학맞통 판정이
  학생마다 따로 이루어집니다.
- 한 학생이라도 저장할 수 없으면 아무것도 저장하지 않습니다. 일부만 저장되는 일은 없습니다.
- 이름 · `2-3` · `2-3-15` · 학번으로 찾을 수 있습니다.

### 가입하지 않은 학생도

지금까지는 앱에 가입한 학생만 K-ODR 검색에 나왔습니다. 학교 적응이 어려운 학생일수록 앱에
가입하지 않았을 가능성이 커서, 지원이 가장 필요한 학생이 가장 먼저 빠지는 구조였습니다.

- 이제 **학생 명단(명렬표)** 전체에서 고릅니다. 가입하지 않은 학생에게는 `미가입` 이
  붙습니다.
- 이달 현황 · 단계 판정 · 학맞통 안건에도 가입하지 않은 학생이 들어갑니다.
- 학생이 나중에 가입하면 그동안의 기록이 그 학생 계정에 저절로 이어집니다.
- **CICO 는 가입한 뒤에 시작할 수 있습니다.** 학생이 앱에서 직접 체크인하는 방식이기
  때문입니다. 이달 현황에 그 안내가 보입니다.

### 공식 기록 보호

- 학생이 스스로 탈퇴하면 그 학생의 K-ODR 과 학맞통 안건이 계정과 함께 지워지게 되어
  있었습니다. 이제는 탈퇴해도 기록이 남고 계정 칸만 비워집니다.
- 기록할 때의 이름 · 학년 · 반 · 번호를 함께 적어 둡니다. 졸업 · 전출로 명단에서 빠져도
  누구의 기록인지 알 수 있습니다.
- 아무도 가입하지 않은 명단 자리의 이름을 고쳐 다른 학생을 넣으면, 그 자리에 있던 기록은
  새 학생에게 넘어가지 않고 원래 학생 이름으로 남습니다.

### 엑스포 체험 학교

표시된 학교에서만 동작하는 것은 그대로입니다.
