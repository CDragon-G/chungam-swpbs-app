# 0.16.1 출시노트

## Google Play — 새로운 기능 (500자 제한)

```
학생이 많은 학교에서도 빠르게 열립니다

학생 목록과 통계를 불러오는 방식을 개선하여, 학생 수가 많아도
화면이 멈추지 않고 빠르게 열립니다.

우리 반 포인트 현황

담임 선생님께서 우리 반 학생들의 포인트 분포를 확인하실 수 있습니다.
평균과 중앙값을 참고하여 강화물 가격을 정하시면 됩니다.

교사 라운지 강화물 편집

등록하신 강화물의 이름과 포인트, 재고를 나중에 수정하실 수 있습니다.
내렸던 강화물을 다시 올리는 것도 가능합니다.
```

## App Store — 이번 버전의 새로운 기능

```
학생이 많은 학교에서도 빠르게 열립니다

학생 목록과 참여 통계를 계산하는 방식을 서버에서 처리하도록 바꾸었습니다.
그동안은 앱이 많은 기록을 한꺼번에 내려받아 직접 계산했는데,
이제 필요한 결과만 받아오므로 학생 수가 많은 학교에서도
화면이 멈추지 않고 빠르게 열립니다. 데이터 사용량도 크게 줄었습니다.

우리 반 포인트 현황

담임 선생님께서 우리 반 학생들의 포인트 분포를 보실 수 있습니다.
평균과 중앙값, 가장 많이 가진 학생의 포인트를 확인하시고
강화물 가격을 정하실 때 참고하시면 됩니다.
전교 현황은 이전처럼 관리자 선생님께만 보입니다.

교사 라운지 강화물 편집

라운지에 등록하신 강화물의 이름과 설명, 포인트, 재고를
나중에 수정하실 수 있습니다. 카드 오른쪽 메뉴에서 편집을 누르시면 됩니다.
내렸던 강화물을 다시 올리는 것도 같은 메뉴에서 하실 수 있습니다.
```
