# 0.25.1 출시노트

자기점검을 하교 후(오후 1시 이후)에만 열도록 했습니다.

## 먼저 — 0.25.0 을 올리셨나요?

- **아직 안 올리셨으면** 0.25.0 은 건너뛰고 **0.25.1 만 올리세요.** 0.25.0 의 명예 식집사와
  칭찬 우체통이 전부 들어 있습니다. 스토어 문구는 아래 "0.25.0 을 건너뛸 때" 를 쓰세요.
- **이미 올리셨으면** 아래 "0.25.0 이 이미 나갔을 때" 문구를 쓰세요.

## 배포 순서

```
1. 056_weekly_honor_gardener.sql   (아직이면)
2. 057_praise_mailbox.sql          (아직이면)
3. 058_checkin_after_school.sql    ← 반드시 056 다음에
4. 0.25.1 을 스토어에 올리고 출시 완료까지 기다린다
5. 버전 게이트 올리기               ← 출시가 끝난 뒤에만
```

**058 은 056 뒤에 실행하세요.** 058 이 이 주의 명예 식집사 계산 함수를 고쳐 쓰는데,
056 을 나중에 실행하면 고치기 전 함수로 되돌아갑니다.

**058 은 앱 업데이트를 기다리지 않고 바로 효과가 납니다.** 시간 제한은 서버가 겁니다.
지금 쓰는 앱에서도 오전에 제출하면 "오후 1시부터 할 수 있어요" 로 거절됩니다. 다만
구버전 앱은 규칙을 전부 체크한 뒤 제출 단계에서 거절되고, 0.25.1 은 점검 화면에
들어가기 전부터 잠겨 있습니다.

5번은 두 컬럼을 같이 올립니다.

```sql
update app_releases
   set latest_version = '0.25.1', min_version = '0.25.1', updated_at = now()
 where platform in ('android', 'ios');
```

## 선생님께 (스토어에 올리지 않는 내용)

### 왜 서버에서 막나

앱에서만 시간을 비교하면 **기기 시계를 오후로 돌리는 순간 뚫립니다.** 예전에 날짜를
앱이 정하게 뒀다가 기기 날짜를 바꿔 포인트를 반복 취득당한 것과 같은 구조입니다.
그래서 한국 시간 기준 서버 시각으로 판단하고, 세 군데를 모두 막았습니다.

| 막는 곳 | 왜 |
|---|---|
| `submit_checkin` | 지금 앱이 점검을 저장하는 길 |
| `daily_checkins` 직접 쓰기 RLS | 0.20.0 이하 구버전 앱이 쓰는 길 |
| 이 주의 명예 식집사 계산 | 아래 설명 |

구버전 앱이 포인트를 받는 길(053 의 껍데기)은 "오늘 점검 기록이 있어야" 지급하기
때문에, 기록을 막으면 포인트도 함께 막힙니다.

### 앱에서 보이는 것

- 1시 전 홈 화면 점검 버튼: **"🕐 자기점검은 오후 1시부터 열려요"** (눌리지 않음)
- 왼쪽 메뉴 "오늘 점검" 의 **"!" 표시도 1시 전에는 숨깁니다.** 할 수 없는 일을 재촉하지 않도록
- 점검 화면에 들어가면 서버에 다시 물어봅니다. 1시 전이면 안내 화면
- 홈을 오전부터 켜둔 채 1시가 지나면 **1분 안에 버튼이 저절로 열립니다**

앱 화면은 기기 시계를 참고해 버튼을 열기도 합니다. 오전에 받아둔 "아직" 상태로
화면을 계속 켜두면 1시가 지나도 잠겨 보이기 때문입니다. 기기 시계를 조작하면 버튼은
열리지만, **제출하는 순간 서버가 거절합니다.**

### 점검 알림

- 1시 이전으로 맞추려 하면 1시로 올리고 안내합니다
- **예전에 오전으로 맞춰둔 학생도** 앱을 열 때 다시 예약되면서 1시로 올라갑니다
- 기본값은 원래대로 오후 5시입니다

### 선생님은 막지 않습니다

오전에 시연하거나 확인하실 일이 있을 수 있어서 **학생 계정만** 시간 제한을 받습니다.
교육청 촬영이 오전이어도 선생님 계정으로는 점검 화면을 보여줄 수 있습니다.
(학생 계정으로 시연하시려면 촬영 시간이 1시 이후여야 합니다)

### 이 주의 명예 식집사도 함께 고쳤습니다

꾸준함 = 점검한 날 / **지금까지의 수업일**. 그런데 화요일 오전에 '오늘' 을 수업일로
세면, 아무도 점검할 수 없는데 분모만 늘어납니다. 모두의 점수가 오전에 반토막 났다가
오후에 돌아옵니다. 그래서 **열리기 전의 오늘은 수업일로 세지 않습니다.**

### 시각 바꾸기

학교마다 따로 정할 수 있습니다. 단축수업이나 시험 기간에 쓰세요.

```sql
-- 1) 우리 학교 id 확인 (학교가 여러 개 등록되어 있어서 이름으로 지정하면 위험)
select id, name, checkin_open_time, created_at from schools order by created_at;

-- 2) 바꾸기 (예: 12시 30분)
update schools set checkin_open_time = '12:30' where id = '<우리 학교 id>';

-- 3) 되돌리기
update schools set checkin_open_time = '13:00' where id = '<우리 학교 id>';
```

**이름으로 지정하지 마세요.** 자람에는 여러 학교가 등록되어 있고, 같은 이름의 학교가
둘 이상이면 모두 바뀝니다.

앱 안내 문구("오후 12시 30분부터")는 이 값을 따라 바뀝니다. 다만 **점검 알림의 최소
시각은 앱에 오후 1시로 고정**되어 있어서, 여는 시각을 1시보다 늦추시면 알림이 여는
시각보다 먼저 올 수 있습니다.
