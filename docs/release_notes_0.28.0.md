# 0.28.0 출시노트

포인트 금액을 학교가 직접 정할 수 있게 했습니다. 이제 포인트를 바꾸려고 앱을 새로
빌드하지 않아도 됩니다. 대시보드 바로가기를 맨 위 아이콘으로 모았고, 칭찬 우체통도
자기점검과 같은 시간에 열립니다. 비슷한 이름 때문에 헷갈리던 '명예 식집사' 세 가지를
구분했습니다.

## 먼저 — 0.27.0 을 스토어에 올리셨나요?

- **아직 안 올리셨으면** 0.27.0 은 건너뛰고 **0.28.0 만 올리세요.** 0.27.0 내용이 전부
  들어 있습니다. 스토어 문구는 아래 "0.27.0 을 건너뛸 때" 를 쓰세요.
- **이미 올리셨으면** "0.27.0 이 이미 나갔을 때" 문구를 쓰세요.

## 배포 순서

```
1. 062_teacher_week_praise_stats.sql     (실행 완료)
2. 063_school_day_streak.sql             (실행 완료)
3. 064_point_rules_mailbox_hours.sql     (실행 완료)
4. 065_group_progress_for_teachers.sql   (실행 완료)
5. 0.28.0 을 스토어에 올리고 출시 완료까지 기다린다
6. 버전 게이트 올리기                      ← 출시가 끝난 뒤에만
```

**064 · 065 는 앱보다 먼저.** 0.28.0 의 포인트 설정 화면과 함께 키우기 진행률이
이 두 파일에서 만드는 함수를 부릅니다.

**064 만으로 바로 적용되는 것 (앱 업데이트 없이)**

- 칭찬 우체통 여는 시간 (구버전 앱에서는 보내기를 누를 때 안내가 뜹니다)
- 포인트 금액 기준 (값을 바꾸려면 0.28.0 의 설정 화면이 필요합니다)

6번은 두 컬럼을 같이 올립니다.

```sql
update app_releases
   set latest_version = '0.28.0', min_version = '0.28.0', updated_at = now()
 where platform in ('android', 'ios');
```

## 선생님께 (스토어에 올리지 않는 내용)

### 포인트 설정 — 앱을 다시 만들지 않아도 됩니다

**대시보드 → 포인트 설정** (관리자 선생님만 바꿀 수 있고, 다른 선생님은 보기만 합니다)

| 항목 | 기본값 | 조절 범위 |
|---|---|---|
| 일일 자기점검 | 100P | 0 ~ 300P (10P 단위) |
| 주간 개근 보너스 | 500P | 0 ~ 2,000P (50P 단위) |
| 선생님 칭찬 | 50P | 0 ~ 300P (10P 단위) |
| 깜짝 퀴즈 정답 | 5P | 0 ~ 100P (5P 단위) |
| 2주 꾸준 식집사 | 500P | 0 ~ 2,000P (50P 단위) |

- 막대를 놓는 순간 저장되고, **그때부터 지급되는 포인트**에 적용됩니다. 이미 받은
  포인트는 건드리지 않습니다.
- **0으로 두면 그 활동에는 포인트를 주지 않습니다.** 강화물 물가에 맞춰 조절하세요.
- 값은 학교마다 따로 저장됩니다. 정하지 않으면 위 기본값을 씁니다.
- 지금까지는 이 숫자들이 서버 함수 안에 박혀 있어서, 바꾸려면 코드를 고치고 마이그레이션을
  새로 실행해야 했습니다.

### 대시보드 바로가기

맨 아래에 세로로 쌓여 있던 버튼 5개를 **맨 위 아이콘 한 줄**로 옮겼습니다. 스크롤하지
않아도 보입니다.

```
보낸 칭찬 · 칭찬 우체통 · 규칙 현황 · 담임반
(관리자) 학맞통 안건 · 건의함 · 포인트 설정 · 명예의 전당
```

### 칭찬 우체통 여는 시간

자기점검과 **똑같은 기준**으로 열립니다. 수업일에만, 그리고 학교가 정한 시각(기본 오후
1시) 이후에만 보낼 수 있습니다. 수업 중에 주고받느라 수업이 흐트러지지 않게 하기
위해서입니다.

- 서버에서 막기 때문에 구버전 앱에서도 바로 적용됩니다. 다만 구버전은 친구와 문장을
  고른 뒤 보내기에서 거절되고, 0.28.0 은 화면에 들어갈 때부터 "1시부터 열려요" 가 뜹니다.
- 받은 편지 읽기는 시간과 상관없이 언제나 됩니다.

### 칭찬 우체통으로 포인트를 쌓을 수 있나요 — 아닙니다

확인해 보니 **칭찬 우체통은 처음부터 포인트를 주지 않습니다.** 친구끼리 주고받으며
포인트를 불리는 일이 생기지 않도록 만들 때부터 뺐습니다(057). 지금 막혀 있는 것은
이렇습니다.

- 포인트 지급 없음
- 한 주에 3번까지, **서로 다른 친구**에게만 (같은 친구에게 두 번 못 보냄)
- 같은 반 친구에게만
- 문장은 서버 목록에서만 고름 (직접 쓰는 글자 없음)
- 이번 0.28.0 부터 수업일 하교 후에만

학생 포인트가 빠르게 늘었다면 일일 점검(100P)과 주간 개근(500P) 쪽입니다. 위 포인트
설정에서 조절하실 수 있습니다.

### '명예 식집사' 가 세 가지였습니다

이름이 비슷해서 대시보드와 명예의 전당이 서로 다르게 보였습니다. 셋 다 살아 있는 기능이고
기준이 다릅니다. 이름을 나눴습니다.

| 이름 | 언제 | 누구 | 어떻게 | 어디 |
|---|---|---|---|---|
| **이 주의 명예 식집사** | 매주 | 반마다 1명 | 자동 (참여·점수·칭찬) | 학생 홈 위에 흐르는 띠 |
| **2주 꾸준 식집사** (이름 바꿈) | 2주 | 전교 1명 | 관리자가 선정 · 포인트 지급 | 대시보드 카드 |
| **이달의 으뜸 식집사** (이름 바꿈) | 한 달 | 전교 1명 | 자동 (칭찬 40 + 참여 30 + 점수 30) | 명예의 전당 |

- 대시보드 카드는 "명예 식집사" → **"2주 꾸준 식집사"**
- 명예의 전당 맨 위는 "이달의 명예 식집사" → **"이달의 으뜸 식집사"**
- 학생 홈의 "이 주의 명예 식집사" 는 그대로 뒀습니다. 학생들이 가장 많이 보는 이름입니다.
- 2주 카드의 포인트 안내에서 '500P' 라는 숫자를 뺐습니다. 이제 학교가 정하는 값이라
  숫자를 적어두면 틀릴 수 있습니다.

### 명예의 전당 — 🛍️ 강화물 교환왕

최근 90일 동안 강화물을 가장 많이 **받아 간**(수령 완료) 학생 1~3위입니다. 몇 개를
받았는지와 쓴 포인트를 함께 보여줍니다. 이름은 가운데를 가립니다.

신청만 하고 아직 받지 않은 것은 세지 않습니다.

### 함께 키우기 진행률 — 선생님 화면에도

**교환소 → 강화물 관리** 에서 '함께 키우기' 강화물마다 막대가 보입니다.

```
320 / 500P · 64% · 12명 참여 · 남은 180P
많이 보탠 학생: 김민수 120P · 이서준 80P · 박지우 50P
```

- 지금까지 진행률은 **학생 화면에만** 있었습니다. 선생님 목록에는 목표 금액만 있어서
  언제 지급하면 되는지 알 수 없었습니다.
- 목표를 채우면 막대가 초록색이 되고, 기존처럼 "목표 달성 — 지급 처리를 해주세요" 가
  함께 뜹니다.
- 지급 완료·환불 처리는 전과 같은 자리(오른쪽 ⋮ 메뉴)에 있습니다.
- 선생님에게는 보탠 학생 이름이 그대로 보입니다. 학생 화면에서도 기여 상위 3명은
  공개되고 있습니다(참여 독려 목적).

### 길게 눌렀을 때 나오는 메뉴

글자를 길게 누르면 나오던 Cut · Copy · Paste 가 **잘라내기 · 복사 · 붙여넣기** 로 나옵니다.
앱에 한국어 기본 설정이 빠져 있어서 영어로 나오고 있었습니다. 날짜 선택기 같은 기본
화면도 함께 한국어가 됩니다.
