# 0.29.0 출시노트

'선생님 관리' 화면이 열리지 않던 오류를 고쳤습니다. 같은 종류의 오류가 더 있는지
앱 전체를 기계로 훑어 확인했습니다. 이메일까지 잊은 학생을 도울 수 있는
**학생 로그인 도움** 화면을 새로 넣었습니다. 0.28.2 의 업데이트 안내 수정도 함께 들어
있습니다.

## 배포 순서

```
1. 067_version_gate_guard.sql   아직이면 (앱과 상관없이 먼저 해도 됩니다)
2. 0.29.0 을 스토어에 올리고 출시 완료까지 기다린다
3. 스토어에서 학생 계정으로 '업데이트' 버튼이 보이는지 확인
4. latest_version 올리기        ← 플랫폼별로 따로
```

**새 마이그레이션은 없습니다.** 0.29.0 은 앱만 바뀝니다.

```sql
-- 3번을 확인한 뒤, 풀린 플랫폼만
update app_releases set latest_version = '0.29.0', updated_at = now()
 where platform = 'android';
```

**지금 iOS 는 `latest_version` 이 0.21.0 으로 내려가 있습니다** (안내를 꺼 둔 상태).
App Store 에 0.29.0 이 출시되면 그때 iOS 도 올려주세요.

## 선생님께

### '데이터 처리 중 오류가 발생했어요' — 원인과 전수 점검

**원인.** `교사 권한 관리 → 선생님 관리` 화면이 선생님 목록을 읽을 때 `profiles` 표의
`name` 컬럼을 함께 요청했는데, **그 표에는 `name` 컬럼이 없습니다**(이름은 `nickname`
에 들어갑니다). 서버가 요청을 통째로 거절해서 화면이 열리지 않았습니다.

이런 실수는 앱을 빌드할 때 걸러지지 않습니다. 화면을 열어봐야만 드러납니다.

**전수 점검.** 같은 종류가 더 있는지 앱 전체를 훑었습니다.

| 검사 | 건수 | 결과 |
|---|---|---|
| 표를 직접 읽는 조회 | 73건 | 없는 컬럼 **1건** (위의 그 화면) |
| 서버 함수(rpc) 호출 | 114건 | 없는 함수 **0건** |

고친 뒤 다시 돌려 0건인 것을 확인했습니다.

**다음에도 쓸 수 있게 점검 도구를 저장소에 넣었습니다.**

```
python tool/audit_queries.py
```

`supabase/migrations/*.sql` 로 스키마를 만들고 `lib/**.dart` 를 훑어, 없는 컬럼이나
없는 서버 함수를 부르는 곳을 찾아줍니다. 화면을 새로 만들거나 조회를 고친 뒤 한 번
돌려보면 같은 사고를 막을 수 있습니다.

### 이메일까지 잊은 학생 — 새 화면

**대시보드 → 로그인 도움**

```
[ 학생 이름 · 2-3 · 2-3-15 · 20315 ]  ← 검색

2학년 3반 14번  김민수
  가입한 이메일   minsu***@naver.com        [복사]
  [이메일 확인]  [비밀번호 초기화]
```

- 이름이나 학년·반·번호, 학번으로 찾습니다.
- **이메일 확인** — 그 학생이 가입할 때 쓴 이메일을 보여줍니다. 학생이 이메일 자체를
  잊었을 때 알려주세요.
- **비밀번호 초기화** — 임시 비밀번호를 만들어 보여줍니다. 학생에게 알려주면 그걸로
  로그인한 뒤 바꾸면 됩니다.
- 둘 다 복사 버튼이 있습니다.

**사실 이 기능 자체는 전부터 있었습니다.** 학생 목록에서 학생을 누르면 나오는 시트 안에
있었는데, 급할 때 찾기 어려운 자리였습니다. 그래서 한 화면으로 따로 빼고 대시보드
바로가기에 넣었습니다. 기존 자리도 그대로 둡니다.

- 우리 학교 학생만 보이고, 서버가 교사인지 확인합니다.
- 관리자가 아니어도 됩니다. 담임이 아닌 선생님도 도와줄 수 있습니다.
- 선생님 계정의 비밀번호 초기화는 전처럼 **교사 권한 관리 → 선생님 관리** 에 있습니다.
  (이제 정상적으로 열립니다)

학생 화면의 '비밀번호 찾기' 에도 "이메일이 기억나지 않으면 담임 선생님께 요청하세요"
안내가 이미 있습니다.

### 대시보드 바로가기 한 칸이 바뀌었습니다

`명예의 전당` 자리에 `로그인 도움` 이 들어갔습니다. 명예의 전당은 선생님 홈의 메뉴에서
그대로 열 수 있습니다.

### 업데이트 안내 (0.28.2 내용)

- 한 번 닫은 버전은 **하루 동안** 다시 묻지 않습니다. 스토어에 새 버전이 아직 퍼지지
  않아 '열기' 만 보이는 동안 되풀이되던 문제입니다.
- 팝업에 안내를 한 줄 넣었습니다.
- 067 을 실행하면 `min_version` 을 `latest_version` 보다 높게 저장할 수 없게 됩니다.
