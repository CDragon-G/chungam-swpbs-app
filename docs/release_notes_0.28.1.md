# 0.28.1 출시노트

함께 키우기(단체 강화물)에 **누가 얼마나 보탰는지 전체 명단**을 넣었습니다.
0.28.0 에서는 많이 보탠 3명까지만 보였습니다.

## 먼저 — 0.28.0 을 스토어에 올리셨나요?

- **아직 안 올리셨으면** 0.28.0 은 건너뛰고 **0.28.1 만 올리세요.** 스토어 문구는
  [release_notes_0.28.0.md](release_notes_0.28.0.md) 의 것을 쓰고 아래 한 줄만 더하세요.

```
함께 키우기에 누가 얼마나 보탰는지 선생님이 명단으로 볼 수 있습니다.
```

- **이미 올리셨으면** 아래 문구를 쓰세요.

## 배포 순서

```
1. 066_group_contributors.sql   앱 배포 전에
2. 0.28.1 을 스토어에 올리고 출시 완료까지 기다린다
3. 버전 게이트 올리기             ← 출시가 끝난 뒤에만
```

```sql
update app_releases
   set latest_version = '0.28.1', min_version = '0.28.1', updated_at = now()
 where platform in ('android', 'ios');
```

## Google Play · App Store — 0.28.0 이 이미 나갔을 때

```
함께 키우기, 누가 얼마나 보탰는지

교환소 → 강화물 관리에서 함께 키우기 강화물의 막대를 누르면
보탠 학생 전체 명단이 열립니다. 많이 보탠 순서로 이름과 포인트,
몇 번에 걸쳐 보탰는지까지 보여줍니다.
```

## 선생님께

### 보탠 학생 명단

**교환소 → 강화물 관리 → 함께 키우기 강화물의 막대를 누르면** 시트가 열립니다.

```
🍪 과자 파티            320 / 500P
보탠 학생 12명 · 많이 보탠 순서

1  2-3-14 김민수    3번에 걸쳐 보탬    120P
2  2-3-07 이서준    한 번에 보탬        80P
3  2-3-21 박지우    2번에 걸쳐 보탬     50P
...
```

- 한 학생이 여러 번 보탰으면 **합쳐서 한 줄**로 보여주고, 몇 번에 걸쳐 보탰는지를 함께
  적습니다.
- 환불된 기록은 세지 않습니다.
- **선생님만 봅니다.** 학생 화면은 지금처럼 많이 보탠 3명까지만 보입니다.
- 우리 학교 강화물만 열립니다. 다른 학교 id 로는 열리지 않습니다.

취소·환불을 하기 전에 누가 얼마나 보탰는지 확인하는 용도로 쓰시면 됩니다. 취소하면
보탠 포인트는 전액 자동으로 돌아갑니다.
