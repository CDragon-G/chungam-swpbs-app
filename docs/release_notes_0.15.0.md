## App Store — 이번 버전의 새로운 기능 (4000자 제한)

```
학사일정에 맞춰 자기점검이 열립니다

주말과 공휴일은 물론, 학교마다 다른 방학과 재량휴업일에도 자기점검이 열리지 않고 알림도 가지 않습니다. 쉬는 날에는 오늘이 어떤 날인지 안내가 나타납니다.

관리자 선생님께서는 교사 홈의 학사일정에서 여름방학, 겨울방학, 봄방학, 재량휴업일, 개교기념일을 기간으로 등록하실 수 있습니다. 2026년과 2027년 공휴일은 미리 반영되어 있습니다.

주간 개근 보너스 기준이 달라졌습니다

그동안은 주 5일을 모두 채워야 보너스를 받을 수 있어, 공휴일이 낀 주에는 아무도 받을 수 없었습니다. 이제 그 주의 실제 수업일을 기준으로 계산합니다.

학급 전체를 한 번에 칭찬하실 수 있습니다

학생을 한 명씩 누르지 않아도 됩니다. 학생 목록에서 여러 명 선택을 켜고 학년과 반을 고른 뒤 전체 선택하시면, 최대 60명에게 같은 칭찬 한마디를 한 번에 보내실 수 있습니다. 받은 학생은 각각 50P와 칭찬 배지를 얻습니다.

알림 방식이 개선되었습니다

매일 같은 시각에 반복되던 알림을 수업일마다 개별 예약하는 방식으로 바꾸어, 쉬는 날에는 알림이 울리지 않습니다.
```
