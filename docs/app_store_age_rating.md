# App Store 연령 등급 설문 — 1단계 '특징' (2026-10-31)

Apple 이 연령 등급을 4+ · 9+ · 13+ · 16+ · 18+ 로 바꾸면서 새로 넣은 질문이다.
App Store Connect → 앱 정보 → 연령 등급 → 1단계.

## 답

| 항목 | 답 | 자람에서 |
|---|---|---|
| **앱 내 제어** · 유해 콘텐츠 차단(보호자 제어) | 아니요 | 보호자가 앱 사용을 모니터링 · 제한하는 기능은 없다 |
| **앱 내 제어** · 나이 확인 | 아니요 | 가입 때 '만 14세 이상 또는 보호자 동의' 체크는 본인 확인일 뿐, Apple 이 말하는 나이 확인(Declared Age Range API · 나이 추정 · 신분증)이 아니다. 학생 PIN 은 재학 확인이지 나이 확인이 아니다 |
| **제공 기능** · 제한되지 않은 웹 액세스 | 아니요 | 앱 안 브라우저가 없다. 홈페이지 · 스토어 링크는 바깥 브라우저 · 스토어 앱으로 연다 |
| **제공 기능** · 사용자 생성 콘텐츠 | **예** | 선생님이 쓴 공지 · 이벤트 포스터가 학교 전체 학생에게 보인다 |
| **제공 기능** · 소셜 미디어 | 아니요 | 좋아요 · 댓글 · 공유로 글이 퍼지는 피드가 없다. 홈의 구름 소식 · 명예의 전당은 앱이 만든 활동 요약이고, 이름은 가려서 보인다 |
| **제공 기능** · 13세 미만 사용자의 소셜 미디어 비활성화 | 아니요 | 소셜 미디어가 없으므로 해당 없음 |
| **제공 기능** · 메시지 및 채팅 | **예** | 선생님 → 학생 칭찬 메시지(직접 쓰는 글), 학생 ↔ 학생 칭찬 우체통(정해진 문장 중 고르기), CICO 멘토 피드백 |
| **제공 기능** · 광고 | 아니요 | 유료 광고가 없다. 학교 이벤트 배너는 학교가 올리는 공지라 광고가 아니다 |

## 등급에 미치는 영향

Apple 의 등급 기준표에서 '사용자 생성 콘텐츠' 와 '메시지 및 채팅' 은 **4+ 에 들어가는 항목** 이다.
두 항목에 '예' 라고 답해도 등급이 올라가지 않는다. 등급을 올리는 것은 '소셜 미디어'(13+) 와
'제한되지 않은 웹 액세스'(16+) 인데 자람은 둘 다 '아니요' 다.

→ 다른 단계(건강 · 폭력 등)에서 '없음' 이면 **4+** 예상.

'예' 로 답했으니 심사에서 사용자 콘텐츠 관리(가이드라인 1.2)를 물을 수 있다. 자람에서 이미 하는 것:

- 공지 · 이벤트는 관리자 선생님만 올리고 지울 수 있다
- 칭찬 우체통은 학생이 글을 직접 쓰지 않고, 받은 학생이 신고하면 선생님이 숨길 수 있다
- 문의: jaramedu.kr@gmail.com (앱 · 홈페이지에 공개)

## 왜 '예' 로 답했나

'아니요' 로 답해도 등급은 같지만, 선생님 공지와 칭찬 메시지는 Apple 정의(사용자가 만든 글이 널리 배포됨 ·
앱 안에서 사용자끼리 직접 소통)에 들어간다. 사실대로 답해 두는 편이 나중에 심사에서 문제가 되지 않는다.
