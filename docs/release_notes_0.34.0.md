# 0.34.0 출시노트

강화물마다 학생 1명이 교환할 수 있는 횟수를 정할 수 있습니다. 끝난 공지는 지우지 않고 내릴 수
있고, 새 공지와 새 강화물은 화면이 꺼진 휴대폰에도 알림이 갑니다. 강화물 순서는 끌어서 옮기거나
가격순으로 정렬합니다.

## 배포 순서

```
1. tool/check_applied.sql 실행 → 0행인지 확인     ← 074 까지 빠진 파일이 없는지
2. 075_exchange_limits.sql                         ← 앱보다 먼저
3. 076_notice_switch_store_order.sql               ← 앱보다 먼저
4. Edge Function send-school-push 배포             ← 아래 참고
5. 0.34.0 을 스토어에 올리고 출시 완료까지 기다린다
6. 스토어에서 학생 계정으로 '업데이트' 버튼이 보이는지 확인
7. latest_version 올리기                           ← 플랫폼별로 따로
```

**Edge Function 배포** — 새 함수 하나를 올립니다. 비밀값(FCM_SERVICE_ACCOUNT)은 칭찬 알림 함수가
쓰는 것을 그대로 씁니다.

- 명령어로: `supabase functions deploy send-school-push`
- 또는 Supabase 대시보드 → Edge Functions → Deploy a new function → 이름 `send-school-push` →
  `supabase/functions/send-school-push/index.ts` 내용을 붙여 넣기

075 · 076 · 함수가 없어도 0.34.0 은 열립니다. 다만 075 전에는 '1인 교환 횟수 제한' 을 켜고 저장하면
오류가 나고, 076 전에는 공지 '게시' 스위치가 오류가 나며, 함수가 없으면 휴대폰 알림만 가지 않습니다.
076 을 실행하면 '게시' 를 끈 공지는 0.33.x 이하 앱의 학생 화면에서도 바로 사라집니다.

```sql
update app_releases set latest_version = '0.34.0', updated_at = now()
 where platform = 'android';   -- iOS 는 App Store 출시를 확인한 뒤 따로
```

## 선생님께

### 1인 교환 횟수 제한

`교환소 → 강화물 관리 → 강화물 추가 · 편집` 에서 개별 강화물의 '1인 교환 횟수 제한' 을 켭니다.

| 기간 | 다시 열리는 때 | 예 |
|---|---|---|
| 하루 | 자정 | 따뜻한 어묵 하루 1개 |
| 한 주 | 월요일 | 점심시간 신청곡 한 주 2번 |
| 한 달 | 다음 달 1일 | 자리 바꾸기 이용권 한 달 1번 |
| 전체 기간 | 다시 열리지 않음 | 특별 이벤트 상품 1인 1번 |

- 학생 교환소 카드에 `하루 1번 · 0/1` 처럼 남은 횟수가 보이고, 다 쓰면 버튼이 '내일 다시' 처럼 바뀝니다.
- 횟수는 서버가 셉니다. 구버전 앱으로 신청해도 막히고 이유가 안내됩니다.
- 선생님이 취소한 교환은 횟수에서 빠집니다.
- 지금 있는 강화물은 모두 '제한 없음' 그대로입니다.
- 함께 키우기는 지금처럼 '1인 최대 포인트' 로 조절합니다.

### 공지 내리기

공지 목록의 각 공지 오른쪽에 **게시** 스위치와 휴지통이 있습니다.

- 스위치를 끄면 학생 화면(홈 배너 · 공지 목록 · 이벤트 팝업)에서 사라집니다. 선생님 목록에는
  흐리게 남아 있고, 다시 켜면 다시 보입니다.
- 휴지통은 지우기 전에 한 번 묻습니다. 지운 공지는 되돌릴 수 없습니다.

### 휴대폰 알림

공지를 올리거나 강화물을 새로 등록하면, 화면이 꺼져 있어도 휴대폰에 알림이 갑니다.

| 무엇을 | 누구에게 |
|---|---|
| 새 공지 · 이벤트 | 우리 학교 학생과 선생님 (올린 선생님 제외) |
| 전교 강화물 | 우리 학교 학생 |
| 학급 강화물 | 그 반 학생 |

- 공지 작성과 강화물 추가 화면에 '휴대폰 알림 보내기' 스위치가 있습니다. 기본은 켜짐입니다.
  강화물 여러 개를 한꺼번에 올릴 때는 꺼 두시면 알림이 여러 번 울리지 않습니다.
- 같은 공지 · 강화물로는 한 번만 보냅니다.
- 알림을 허용한 기기에만 갑니다. 휴대폰 설정에서 자람 알림을 끈 기기에는 가지 않습니다.
- 새 공지도 이제 앱 안 알림(종)에 남습니다. 새 강화물은 원래 남았습니다.

### 강화물 순서

`교환소 → 강화물 관리` 에서 각 강화물 오른쪽 손잡이(⠿)를 끌어 순서를 바꿉니다. 학생 교환소도 이
순서대로 보입니다.

- 관리자 선생님은 위의 '가격 높은 순' · '가격 낮은 순' 으로 한 번에 정렬할 수 있습니다.
- 일반 선생님은 자기가 등록한 강화물만 옮길 수 있습니다 (지금의 편집 권한과 같습니다).
