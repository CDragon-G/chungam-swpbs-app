# Google Play Console 등록용 콘텐츠 (한글)

Play Console에 입력할 때 그대로 복사해서 쓰세요.
각 필드의 글자 수 제한이 있으므로 임의로 늘리거나 줄이지 마세요.

---

## 1. 앱 이름 (최대 30자)

```
자람 - 학교 행동 자기점검
```

## 2. 짧은 설명 (최대 80자)

```
매일 1분, 우리 학교 약속을 스스로 점검하며 함께 자라요. 교사·학생을 위한 SWPBS 앱.
```

## 3. 자세한 설명 (최대 4,000자)

```
🌱 자람은 학교의 긍정적 행동지원(SWPBS)을 매일 한 자리에서 운영할 수 있도록 만들어진 모바일 앱입니다.

[학생을 위한 기능]
• 매일 1분 자기점검 — 수업·교실·복도·급식실·화장실 등 우리 학교 약속을 O/X로 체크
• 점수 자동 계산 + 카테고리별 분석 (수업3끝, M예의, R책임, S안전)
• 마이페이지에서 30일 점수 추이, 참여 캘린더, 카테고리 레이더 차트 확인
• 연속 참여 스트릭과 다양한 뱃지로 동기부여
• 우리 반·학년·전교 평균과 비교 (익명, 개인 정보 노출 없음)

[교사를 위한 기능]
• 6자리 학교 코드로 학교를 만들고 학생들을 초대
• 학교만의 규칙 자유 편집 (공간별·카테고리별)
• 학교 전체/반별/학생별 대시보드
• 오늘 참여율, 주간 평균 점수, 취약 규칙 Top 3
• 3일 이상 미참여 학생 자동 알림
• 학교 공지사항을 학생들에게 일괄 발송

[안전한 데이터 관리]
• 학교 코드 기반 격리 — 다른 학교 데이터에 접근할 수 없습니다
• 모든 응답은 본인만 볼 수 있고, 교사는 통계 형태로만 확인합니다
• 광고 식별자 수집 없음, 제3자 광고 SDK 없음
• 14세 미만 사용자는 보호자 동의 후 가입

[누구를 위한 앱인가요?]
• 초·중·고등학교 담임교사
• 학교 행동지원(SWPBS) 운영 교사
• 일일 자기점검 활동을 도입하고 싶은 학생회·교사

[가입 방법]
1) 교사가 먼저 가입 → 학교 등록 → 6자리 학교 코드 발급
2) 학생은 학교 코드 입력 후 본인 정보 입력하여 가입
3) 매일 종례 시간에 1분 자기점검

문의 및 건의: (운영자 이메일)
개인정보처리방침: (개인정보처리방침 URL)
```

## 4. 카테고리

- **앱 카테고리**: 교육
- **태그**: 학교, 교육, 자기관리, 행동지원, SWPBS, 학급운영, 청소년

## 5. 콘텐츠 등급

설문에 다음과 같이 답하세요:
- 폭력성: **없음**
- 성적 콘텐츠: **없음**
- 욕설: **없음**
- 약물: **없음**
- 도박: **없음**
- 무서운 콘텐츠: **없음**
- 사용자 간 상호작용: **있음** (교사 공지, 익명 순위)
- 개인정보 공유: **있음** (학교 통계 목적)
- 디지털 구매: **없음**

→ 결과: **전체이용가 (Everyone)** 예상

## 6. 대상 연령

- **주 대상**: 만 6세 이상 (초등생 포함 시) 또는 만 13세 이상 (중·고만)
- **부가 대상**: 만 18세 이상 (교사)

⚠️ 초등생을 포함하면 **Google Play "Families" 정책** 적용:
- 광고 SDK 추가 금지 (현재 자람은 광고 없으므로 OK)
- 분석 SDK도 제한
- 개인정보처리방침 더 엄격

## 7. 데이터 안전 양식 (Data Safety)

Play Console에서 묻는 항목 답안:

**개인 정보**:
- 이름: ✅ 수집 (닉네임), 필수, 앱 기능
- 이메일 주소: ✅ 수집, 필수, 계정 관리

**금융 정보**: ❌ 수집 안 함
**위치**: ❌ 수집 안 함
**사진 및 동영상**: ❌ 수집 안 함
**오디오**: ❌ 수집 안 함
**파일 및 문서**: ❌ 수집 안 함
**캘린더**: ❌ 수집 안 함
**연락처**: ❌ 수집 안 함
**앱 활동**: ✅ 수집 (자기점검 응답), 필수, 앱 기능 + 분석
**웹 검색 기록**: ❌
**기기 또는 기타 ID**: ❌

**암호화 전송 여부**: ✅ 예 (HTTPS/TLS)
**삭제 요청 가능 여부**: ✅ 예 (앱 내 탈퇴 + 운영자 이메일)
**광고용 데이터 공유**: ❌ 없음

## 8. 그래픽 요건

| 항목 | 규격 | 비고 |
|---|---|---|
| **앱 아이콘** | 512×512 PNG | 이미 있음 (assets/icon/icon.png 활용) |
| **피처 그래픽** | 1024×500 PNG | Play Store 상단 배너 — Canva로 무료 제작 |
| **휴대전화 스크린샷** | 최소 2장, 권장 8장 | 320~3840px |
| **태블릿 스크린샷** | 선택 | 없어도 됨 |

### 스크린샷 추천 (4~6장):
1. 환영 화면 (자람 로고 + 슬로건)
2. 학생 홈 (스트릭 + 오늘 카드)
3. 자기점검 화면 (O/X 버튼)
4. 마이페이지 (차트들)
5. 교사 대시보드
6. 뱃지 갤러리

폰에서 직접 캡처:
- 갤럭시: 전원 + 음량 하 동시 누름
- 캡처 후 `갤러리 > 캡처 폴더`에서 확인

## 10. 출시 트랙 전략

1. **내부 테스트** (immediate, 1~2명) — 본인+동료 1명
2. **비공개 테스트** (1주, 10~50명) — 한 학교 교사+학생 대상
3. **공개 테스트** (선택, 무제한) — 베타로 등록
4. **프로덕션** (정식 출시) — 모든 사용자

처음엔 **내부 테스트만** 사용. 단점 발견 시 빠르게 수정 후 재배포.
