## 선생님께 (스토어에 올리지 않는 내용)

무엇이 뚫렸는지 정리해 둡니다.

**1. 날짜를 앱이 정했습니다.**
"오늘 수업일인가" 검사는 서버 시간으로 제대로 했지만, 저장할 때는 기기 시간으로
만든 날짜를 그대로 썼습니다. 평일에 기기 날짜를 토요일로 바꾸면 검사는 통과하고
토요일 기록이 남았습니다.

**2. 포인트 지급 함수가 열려 있었습니다.**
`award_checkin_points` 가 사용자 ID 와 날짜를 파라미터로 받았고 앱에서 호출할 수
있었습니다. 앱을 고치지 않고 API 만 직접 불러도 아무 날짜로나, 남의 계정으로도
포인트를 넣을 수 있었습니다.

**3. 점수도 앱이 계산해 보냈습니다.**
조작하면 통계와 명예 식집사 선정이 왜곡됩니다.

세 가지를 모두 서버로 옮겼습니다. 앱은 이제 "어떤 규칙을 지켰는지"만 보냅니다.
