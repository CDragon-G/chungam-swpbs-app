
## 선생님께 (스토어에 올리지 않는 내용)

### 어떻게 동작하나

`app_releases` 표의 `min_version` 이 기준입니다. 앱이 그보다 낮으면

- 로그인 버튼을 눌러도 진행되지 않고 안내창이 열립니다
- 가입도 같은 방식으로 막힙니다
- 이미 로그인해 둔 사람은 앱을 열 때 닫을 수 없는 안내창을 만납니다

안내창의 버튼을 누르면 스토어로 바로 갑니다.

### 통신이 끊기면

버전 확인에 실패하면 **그냥 통과시킵니다.** 서버가 잠깐 불안정하다고
학교 전체가 로그인을 못 하는 편이 훨씬 위험합니다.

### 잠금을 풀어야 할 때

Play 단계적 출시가 늦거나, 구형 안드로이드라 업데이트를 못 받는 학생이
생기면 `min_version` 만 낮추면 됩니다. 앱을 다시 배포할 필요가 없습니다.

```sql
-- 잠금 해제 (안내만 뜨고 로그인은 됨)
select set_version_gate('android', '0.20.1');

-- 다시 잠그기
select set_version_gate(null, '0.21.0');

-- 현재 상태 확인
select platform, latest_version, min_version, updated_at from app_releases;
```

`latest_version` 은 그대로 두시면 "새 버전이 나왔어요" 안내는 계속 뜹니다.
