# 자람 교육 엑스포 체험 부스 안내서

서울시교육청 학생맞춤통합지원 부스 · 태블릿 6대 (학생 3 + 선생님 3)

## 1. 구성

충암중과 완전히 분리된 **체험 학교**를 따로 만듭니다. 자람은 모든 기록을 학교 단위로
나누기 때문에, 체험 학교에서 무엇을 해도 충암중의 점검·통계·명예의 전당·학교 새싹에
섞이지 않습니다.

| | 이름 |
|---|---|
| 학교 | **자람체험중학교** (서울특별시 · 중학교) |

| 세트 | 선생님 태블릿 | 학생 태블릿 | 보여주기 좋은 것 |
|---|---|---|---|
| A | **한햇살** 선생님 (1학년 1반 담임) | 1학년 1반 1번 **김새싹** | 꾸준한 학생 · 14일 연속 불꽃 |
| B | **윤바람** 선생님 (1학년 2반 담임) | 1학년 2반 1번 **이꽃잎** | 칭찬 · 칭찬 우체통 · 교환소 |
| C | **서단비** 선생님 (1학년 3반 담임) | 1학년 3반 1번 **박열매** | **K-ODR → CICO → 학맞통 연계** |

- 이름은 모두 지어낸 것입니다. 햇살·바람·단비는 새싹을 키우는 것들, 새싹·꽃잎·열매는
  자라는 순서라 자람 이야기와 맞췄습니다.
- 명예의 전당·명예 식집사에는 가운데를 가려 `김*싹`, `이*잎`, `박*매` 로 나옵니다.
- **C 세트가 학맞통 시연용입니다.** 박열매 학생에게 가벼운 K-ODR 5건이 미리 들어가 있어,
  선생님 화면에서 CICO 권장 알림과 학맞통 연계 안건이 자동으로 생긴 모습을 보여줄 수
  있습니다. 장학사님께 설명하실 때 이 세트를 쓰시면 됩니다.

## 2. 체험 학교만 다르게 동작하는 것

| | 일반 학교 | 체험 학교 |
|---|---|---|
| 자기점검 · 칭찬 우체통 | 수업일 오후 1시부터 | **언제든** (오전·주말도) |
| 하루 점검 | 1번 | 1번 — 대신 **체험 초기화**로 다시 할 수 있게 됨 |
| 탈퇴 | 가능 | **막힘** (관람객이 실수로 누르는 것 방지) |
| 학생 로그아웃 | 바로 | **한 번 묻기** |
| 전국 학교 순위 | 나옴 | 안 나옴 |
| 학생 화면 | 당겨서 새로고침 | **30초마다 저절로** 새로고침 |

## 3. 준비 (행사 1~2주 전)

### ① 서버 준비
Supabase SQL 에디터에서 차례로 실행합니다.
```
068_account_cleanup.sql
069_expo_demo_school.sql
```

### ② 선생님 계정 3개 만들기
- **이메일 팁:** 지메일은 아이디 뒤에 `+아무글자` 를 붙여도 같은 메일함으로 옵니다.
  예) `내아이디+expo1@gmail.com`, `내아이디+expo2@gmail.com` … 메일 계정을 새로 만들 필요가 없습니다.
  (네이버 메일은 이 기능이 없습니다)
- 비밀번호는 부스 선생님들이 외우기 쉬운 것으로 셋 다 같게 두셔도 됩니다.

1. **한햇살** 선생님으로 가입 → **새 학교 등록** → `자람체험중학교` · 서울특별시 · 중학교
2. SQL 에디터에서 아래를 실행합니다. **학생 PIN 3개가 결과에 나옵니다.** 적어두세요.
   ```sql
   select setup_demo_school((select id from schools where name = '자람체험중학교'));
   ```
3. 한햇살 선생님 앱의 **학교 코드** 화면에서 **교사 코드**를 확인합니다.
4. **윤바람**, **서단비** 선생님을 차례로 가입 → **기존 학교 참여** → 교사 코드 입력.
   (가입 순서대로 1·2·3반 담임이 됩니다. 순서를 지켜주세요)

### ③ 학생 계정 3개 만들기
**학교 코드**(교사 코드와 다름)와 위에서 받은 PIN으로 가입합니다.
이름은 명렬표에서 자동으로 들어가므로 학년·반·번호만 맞게 넣으면 됩니다.

| 학생 | 학년 | 반 | 번호 |
|---|---|---|---|
| 김새싹 | 1 | 1 | 1 |
| 이꽃잎 | 1 | 2 | 1 |
| 박열매 | 1 | 3 | 1 |

### ④ 마무리 — 한 번 더 실행
모든 계정이 가입된 뒤 **같은 SQL을 한 번 더** 실행합니다.
```sql
select setup_demo_school((select id from schools where name = '자람체험중학교'));
```
이때 담임 배정(1·2·3반), 관리자 권한, 예시 데이터가 모두 채워집니다.

결과의 `reset` 항목에 `"students": 3`, `"teachers": 3` 이 보이면 준비 끝입니다.
`note` 에 문구가 있으면 K-ODR 예시만 빠진 것이니 알려주세요.

### ⑤ 태블릿 설정
- 6대 모두 자람 **0.30.0 이상** 설치
- 선생님 태블릿 3대: 각 선생님 계정으로 로그인 → 하단 **대시보드** 탭을 열어 둠
- 학생 태블릿 3대: 각 학생 계정으로 로그인 → 홈 화면에 둠
- **앱 고정** (관람객이 다른 앱으로 나가지 못하게)
  - 안드로이드: 설정 → 보안 → **앱 고정** 켜기 → 최근 앱 화면에서 자람 아이콘 → 고정
  - 아이패드: 설정 → 손쉬운 사용 → **사용법 유도** 켜기 → 자람에서 측면 버튼 세 번
- 화면 자동 꺼짐: **안 함** 또는 가장 길게
- 알림 허용 (칭찬을 보내면 학생 태블릿에 바로 뜨는 게 가장 인상적입니다)
- 행사장 와이파이는 불안정한 경우가 많습니다. **휴대폰 핫스팟**을 하나 준비하세요.
- 충전기 · 멀티탭

## 4. 부스 운영

### 관람객 한 팀의 흐름 (3~5분)

**학생 태블릿에서**
1. 오늘의 자기점검 → 규칙마다 O/X → 점수와 포인트, 학교 새싹이 자람
2. 칭찬 우체통 → 같은 반 친구에게 문장을 골라 칭찬 보내기
3. 교환소 → 포인트로 강화물 신청, 반 친구들과 '함께 키우기'

**선생님 태블릿에서**
1. 학생 목록 → 칭찬하기 → **학생 태블릿에 알림이 바로 뜸**
2. 대시보드 → 오늘 참여율 · 반별 · 주간 점검표
3. (C 세트) K-ODR → 박열매 학생 기록 → **학맞통 연계 안건** 화면
4. 교환소 → 방금 학생이 신청한 강화물 지급 처리

### 다음 관람객으로 넘어갈 때
그 세트의 선생님 태블릿 **대시보드 맨 위 🎪 → 우리 반 초기화** 를 누릅니다.
- **그 세트만** 처음으로 돌아갑니다. 다른 두 세트에서 체험 중인 관람객 기록은 그대로입니다
- 오늘 한 점검·칭찬·편지·교환이 지워지고, 그 학생의 예시 데이터(최근 14일 점검, 칭찬,
  함께 키우기, C 세트는 K-ODR)가 다시 채워집니다
- 학생 태블릿은 30초 안에 저절로 따라옵니다. 급하면 홈 화면을 아래로 당기세요
- 옆의 **학교 전체** 는 세 세트를 한꺼번에 되돌립니다. 아침에 문 열 때나 문제가 생겼을 때 쓰세요

### 학교 새싹 축하 팝업
초기화할 때마다 "학교가 자랐어요" 축하 팝업이 다시 뜹니다. 관람객에게 보여주기 좋은
장면이니 그대로 두셔도 됩니다.

## 5. 이럴 땐

| 상황 | 할 일 |
|---|---|
| 학생 태블릿이 로그아웃됐다 | 학생 계정으로 다시 로그인 (그래서 체험 학교는 로그아웃 전에 한 번 묻습니다) |
| "오늘은 이미 점검했어요" | 그 세트 선생님 태블릿에서 우리 반 초기화 |
| 칭찬 우체통이 "이번 주 3번 다 썼어요" | 우리 반 초기화 |
| 초기화 버튼이 안 보인다 | 선생님 계정인지, 앱이 0.30.0 이상인지 확인 |
| 초기화가 실패한다 | SQL 에디터에서 `select reset_demo_school((select id from schools where name = '자람체험중학교'));` |
| 인터넷이 끊겼다 | 핫스팟으로 전환 |

## 6. 행사가 끝나면

체험 학교는 그대로 두면 다음 행사에 다시 쓸 수 있습니다. 결제 대상이 아니고 전국 순위에도
나오지 않습니다. 정리하고 싶으시면 알려주세요 — 학교째 지우는 방법을 따로 안내하겠습니다.

## 7. 안전장치 (충암중이 오염되지 않는 이유)

- 모든 기록은 학교 번호로 나뉘고, 서버가 학교 번호를 검사합니다.
- **체험 초기화는 체험 학교로 표시된 학교에서만 동작합니다.** 충암중 선생님이 버튼을 부를
  방법이 없고, 불러도 서버가 거절합니다.
- 학생이 10명 넘는 학교는 체험 학교로 바꿀 수 없습니다. 운영 중인 학교를 실수로 체험
  학교로 바꾸는 사고를 막기 위해서입니다.
- 체험 학교는 전국 학교 순위에서 빠집니다.
