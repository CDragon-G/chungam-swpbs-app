# 0.30.0 출시노트

관리자 선생님이 테스트로 만든 학생 계정을 지울 수 있게 했습니다. 선생님 계정 삭제가
실패하거나 칭찬 기록이 함께 사라지던 문제를 고쳤습니다. 교육 엑스포 부스에서 쓸
**체험 학교** 기능을 넣었습니다.

## 배포 순서

```
1. 068_account_cleanup.sql     (실행 완료)
2. 069_expo_demo_school.sql    (실행 완료)
3. 0.30.0 을 스토어에 올리고 출시 완료까지 기다린다
4. 스토어에서 학생 계정으로 '업데이트' 버튼이 보이는지 확인
5. latest_version 올리기        ← 플랫폼별로 따로
```

```sql
update app_releases set latest_version = '0.30.0', updated_at = now()
 where platform = 'android';   -- iOS 는 App Store 출시를 확인한 뒤 따로
```

## Google Play · App Store — 이번 버전

```
관리자 선생님이 테스트로 만든 학생 계정을 정리할 수 있습니다.
학생 목록에서 학생을 누르면 '학생 계정 삭제' 가 있습니다.
K-ODR 이나 학맞통 기록이 있는 학생은 공식 기록 보호를 위해 삭제되지 않습니다.

선생님 계정 삭제가 되지 않던 문제를 고쳤습니다.
선생님 계정을 지워도 그 선생님이 보낸 칭찬은 학생에게 그대로 남습니다.
```

## 선생님께

### 선생님 계정 삭제 — 세 겹으로 막혀 있었습니다

`교사 권한 관리 → 선생님 관리 → 계정 삭제` 는 사실상 한 번도 성공하지 못했을 가능성이
큽니다.

| 막힌 이유 | 해당하는 선생님 |
|---|---|
| 서버 함수가 `profiles` 에 없는 `name` 컬럼을 읽음 (0.29.0 화면 오류와 같은 원인) | **모든 선생님** |
| 강화물 '지급 처리' 기록에 삭제 규칙이 없음 | 교환을 한 번이라도 처리한 선생님 |
| K-ODR 작성자가 '비우면 안 됨' 인데 '교사 삭제 시 비움' 으로 충돌 | K-ODR 을 한 번이라도 쓴 선생님 |

068 이 셋 다 고칩니다. 이제 선생님이 떠나도 교환 기록과 K-ODR 은 남고 작성자만
비워집니다.

**더 큰 문제가 하나 있었습니다.** 선생님 계정을 지우면 **그 선생님이 보낸 칭찬이 전부
함께 지워지도록** 되어 있었습니다. 삭제 확인 창에는 "남기신 칭찬과 기록은 그대로
있습니다" 라고 적혀 있었는데 사실이 아니었습니다. 위의 이유로 삭제 자체가 실패해서 실제로
지워진 적은 없었을 것입니다. 이제는 칭찬이 남고 보낸 선생님만 비워지며, 학생 화면에는
'선생님' 으로 보입니다.

### 테스트 학생 계정 삭제 (관리자)

**학생 목록 → 학생 누르기 → 학생 계정 삭제**

- 관리자 선생님만 보입니다.
- 그 학생의 점검 · 포인트 · 뱃지 · 칭찬이 함께 지워지고 되돌릴 수 없습니다.
- **K-ODR 이나 학맞통 안건이 있는 학생은 서버가 거부합니다.** 공식 기록이 함께 사라지기
  때문입니다. 전학 · 졸업한 실제 학생은 지우지 말고 명렬표 진급 처리로 정리해주세요.
- **명렬표 자리는 다시 가입할 수 있게 풀어 줍니다.** 테스트 계정이 실제 학생의 자리를
  쓰고 있었다면, 삭제 뒤 그 학생이 같은 번호와 PIN 으로 가입할 수 있습니다.

### 학생이 스스로 탈퇴했을 때

지금까지는 탈퇴해도 명렬표 자리가 '가입됨' 으로 잠긴 채 남아, 같은 번호로 다시 가입하려
하면 "이미 가입에 사용된 학번이에요" 가 떴습니다. 068 이 탈퇴 때 자리를 풀고, **이미 잠겨
있던 자리도 한 번에 풀어 줍니다.**

### 엑스포 체험 학교

자세한 준비 방법은 [expo_booth_guide.md](expo_booth_guide.md) 에 있습니다.

- 충암중과 완전히 분리된 학교(`자람체험중학교`)를 따로 둡니다.
- 체험 학교는 매일이 수업일이고 자기점검 · 칭찬 우체통이 하루 종일 열립니다.
- 선생님 대시보드 맨 위의 **🎪 우리 반 초기화** 로 그 세트만 처음 상태로 되돌립니다.
  최근 14일 점검 · 칭찬 · 함께 키우기 · (C 세트) K-ODR 예시가 다시 채워집니다.
- 학생 태블릿은 30초마다 저절로 새로 고칩니다.
- 체험용 계정은 탈퇴할 수 없고, 학생 로그아웃은 한 번 묻습니다.
- 체험 학교는 전국 학교 순위에 나오지 않습니다.
- **초기화는 체험 학교로 표시된 학교에서만 동작합니다.** 충암중에서는 버튼이 보이지 않고,
  서버도 거절합니다.
